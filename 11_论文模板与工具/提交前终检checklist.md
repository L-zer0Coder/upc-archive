# 提交前终检 Checklist —— 按 7 条评审不变量逐项打勾

> 打印出来三人各过一遍。任何一条 ✗ 都比少算一个修正项更伤分。

## A. 判据与去模糊化
- [ ] 题面中每个模糊词（significant/quickly/safely/damage…）都被翻译成了可计算的判据
- [ ] 每个阈值都有"为什么是这个数"的一句自辩（学 2010-A 的 20% 燃耗）
- [ ] 判据在同一处集中定义，全文不再改变口径

## B. 基准与锚点
- [ ] 有一个解析可得的对照方案（§1 或等价位置）
- [ ] 所有关键参数有出处：文献引用 / 现实类比 / 定义本身（如 1 bar 半径）
- [ ] 结论区回扣了基准的对比数字（"500 kg vs 2378 kg"式）

## C. 模型与推导
- [ ] 主方程从基本定律出发，无"obviously/easily shown"跳步
- [ ] 每个简化假设旁有一行量级论证或文献理由
- [ ] 组合参数（Define σ≡…）让方程保持整洁
- [ ] 模型适用域被明说（"valid between R_N and R_atm"式声明）

## D. 数值与验证（三件套缺一不可）
- [ ] 方法名+步长+初值+边界条件五要素齐全
- [ ] 步长减半（或等价收敛检验）给出有效位数声明
- [ ] 至少一个极限情形退化为解析解/基准
- [ ] 核心参数灵敏度扫描有图（龙卷风图或 ±% 表）
- [ ] 误差/适用域有专门段落，且点名最坏情形

## E. 图表（用 11_论文模板与工具/图表配方库 对照）
- [ ] 每张图有编号、被正文点名（"Figure N shows…"）
- [ ] 轴标签带单位；坐标比例合理（轨迹图 equal aspect）
- [ ] 核心图遵循"结论进图题"（数值写进 title）
- [ ] 全文配色语义一致（同一对象永远同色）
- [ ] 图不少于 4 张、不多于 10 张；每图只讲一个结论

## F. 写作与结构
- [ ] 摘要一页内完成：符号定义→两难→方法→**数值结论**
- [ ] 摘要含至少一个区间/阈值/百分比硬数字
- [ ] 章节顺序与"模板结构"一致或有意偏离并有理由
- [ ] 无自夸词（accurate/great），改用精度声明
- [ ] 引用 5–15 条，注明访问日期；每条都被正文引用过
- [ ] 附录含可复现代码（关键循环完整）

## G. 提交合规
- [ ] 标题页只有队号+题号+标题（无校名人名——匿名评审）
- [ ] 页数 ≤ 上限（通常 25 页正文 + 附录，按当年规则）
- [ ] PDF 字体嵌入、公式无乱码、无 "Figure ??" 断链
- [ ] 提前 2 小时上传，官网确认收到

## 评委三分钟视角模拟
最后做一次：只读 标题+摘要+全部图题，5 分钟内能否复述——
①问题 ②判据 ③方法 ④主结果数字 ⑤结论与适用域？
复述不出哪条，就回去补哪条。
