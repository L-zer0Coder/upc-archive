# 符号速查表 —— 看不懂公式里的符号？从这里查

**本文定位**：全库公式中符号的"翻译层"。术语速查表管**词**（aerobraking 是什么），本表管**符**（ρ、σ、Δv 怎么读、是什么）。配合阅读路径：公式怎么从无到有——新手课堂课程一（圈三样→变量表→选骨架→插零件）→ 零基础起步卡（五层）→ 本文查符号。

**最大陷阱先说**：**同一个符号在不同论文里意思不同**。物理符号没有国家标准，每支队伍自己定义——所以读任何公式前，先找该论文的符号表（规范论文必有）。本表给的是 **UPC 语料中的高频含义**，按出现频次排序；⚠ 标记 = 一词多义重灾区。

## 3. 上下标与记号惯例

| 记号 | 读法 | 例 |
|---|---|---|
| x₀ | 下标 0 = 初始值/基准值 | v₀ 初速、h₀ 起跳高 |
| x∞ | 下标 ∞ = 远场/无穷远 | v∞ 引力辅助时的双曲线超速 |
| x_max / x_min | 最大 / 最小（临界往往由这两个夹逼） | θ_max−θ_min=窗口 |
| x_eff | 有效值（把复杂效应打包成一个参数） | C_dA 有效迎风面积、D_eff 有效扩散率 |
| Δx | 末值 − 初值（差分） | Δv、Δθ |
| d x/d t | 对时间的导数（变化率） | dv/dt=加速度 |
| ∂ | 偏导数（多元函数只对一个变量求导） | ∂T/∂t |
| Σ | 求和（ΣF=所有力加起来） | 牛顿第二定律 ΣF=ma |
| ∝ | 正比于（读"正比"） | 全力 ∝ 1/r² |
| ≈ / ≈10ⁿ | 近似 / 量级是 | on the order of |
| ×10ⁿ | 科学计数法（10⁴=一万） | 中文"万/亿"一律换算成这个 |
| v̂（帽子） | 单位向量（方向） | 阻力 −½ρC_dAv²·v̂ |

## 4. 三步读懂一条公式（教学口诀）

1. **先读符号**：每个符号是什么量、什么单位——不认识的回本表或该论文符号表；
2. **再读结构**：等号两边各是什么（力=力？能量入=能量出？）——物理方程都是"收支/平衡/变化率"三句话之一；
3. **最后读量级**：把数字代入粗算一遍（费米估算），确认公式说的是人话。

> 公式不是天书，是**压缩的实验记录**：每一个符号都是一个被测量过的量，每一项都是一个被论证过"必须建模"的物理效应。看不懂时，缺的从来不是数学，是**这个符号背后的那句话**——回变量表和解读里找它。
