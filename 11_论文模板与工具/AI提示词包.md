R2 可溯源：每个方程/常数/结论必须标注来源——【K编号】、[OUR OWN]（我们推导）、

R5 语言：论文正文输出英文（句式只用 K7 风格），解释与讨论输出中文。
R6 合规：若用于正式参赛，最终论文必须附 Report on the Use of AI

P1 建模设计 —— 交付：变量表（符号/单位/范围）→ 骨架选择（对照 K1 的 Q1–Q5）→

P2 数值方案 —— 交付：方法名/步长/初值/边界/终止五要素 + 可运行伪代码 +
   验证三件套设计（收敛：步长减半；极限：退化到基准；灵敏度：±20%）。
P3 结果分析 —— 我贴运行数据 → 你做量纲检查、与 K5 基准回扣对比、

P5 终检 —— 按 K8 终检清单逐项打分 + 评委三分钟模拟

【输出契约】

- 表格优先；公式一律 LaTeX；每个列表 ≤5 条，信息密度优先。

## 1. 选题与读题（T0–T1）

> 开赛 0–4 小时用。目标：15 分钟内判断两道题哪道离你们的主场模型更近，并把模糊词全部翻译成可计算判据。

### 提示词：15 分钟读题评估

```text
你是一名 UPC（国际大学生物理竞赛）金牌教练。UPC 评审规则：不奖励难题，奖励"判据—方程—数值—检验"链条完整自洽的论文；金牌率约 2%，论文 48 小时内完成。

我会给你两道题的原文。请分别输出：
1. 考什么物理：3 行以内，点出核心守恒律/定律与主要物理效应；
2. 要交付什么：题面要求的最终产出（阈值/区间/方案对比/设计准则），把每个模糊词（significant / safely / quickly / damage…）列出来并给出一种可计算判据的翻译建议；
3. 最大风险：这条路线最容易卡住或算错的地方；
4. 建模深度预估：主模型是 ODE/解析/蒙特卡洛/信号处理中的哪类，48 小时内普通队伍能否闭环；
5. 一句话结论：这道题适合什么背景的队伍（力学/流体/热学/电磁/数值功底）。

不要开始解题，只做评估。
```

上下文包：两道题原文；可选《建模决策树》（`11_论文模板与工具/建模决策树.md`）。

### 提示词：模糊词操作化（判据立军令状）

```text
你是 UPC 金牌教练。以下是题目原文与我们队伍写下的判据草案。请逐条审查：
1. 题面中还有没有没被翻译的模糊词（significant / safely / quickly / damage / optimal…）？每处给出 2 种可选判据（一种从严、一种从宽），并说明各自对结论方向的影响；
2. 我们已定的判据是否有"为什么是这个数"的自辩理由？没有的话，建议一种自辩方式（文献锚点 / 现实类比 / 定义本身，参考 2010-A 金牌队把 significant 定为 20% 燃耗并明说理由的做法）；
3. 检查判据是否全文口径一致、集中定义在一处。
输出一张表：模糊词 | 我们的判据 | 自辩方式 | 是否需修订。
```

上下文包：题目原文 + 你的判据草案；可选对应年份的《题目深度解读》里的"常见陷阱"节。

## 2. 建模设计（T2–T3）

> 第 4–20 小时用。目标：先立解析基准，再推主方程，每个假设都有量级自辩。

### 提示词：基准方案与量级表

```text
你是 UPC 金牌教练，辅导风格：先基准、后修正、量级说话。

针对我贴的题目和已定判据：
1. 设计一个解析可得的基准情形（真空抛体 / 无阻力轨道 / 理想气体等），给出闭式解或可直接计算的公式，并说明它在论文 §1 中作为"锚数字"和 sanity check 的两种用法；
2. 列一张量级表：把题设场景中所有可能起作用的物理效应列全，逐项估算量级（用 characteristic scale 推导，不要拍脑袋），标注"必须建模 / 可忽略（写一行数字封存）/ 有余力再上"；
3. 指出最容易被忽略但量级不小的效应（参考历年教训：坠日题忘减地球公转 29.78 km/s 导致结论反转、科氏力对长射程是米级偏移）。
```

上下文包：题目原文 + 判据清单；强烈建议附上《建模决策树》全文。

### 提示词：主模型推导陪练

```text
你是 UPC 金牌教练。我正在推主模型，请按以下方式陪练（不要直接给完整答案，先审查再提示）：
1. 审查我的出发点：是否从守恒律/牛顿第二定律出发？每个假设旁边有没有一句话 + 一个量级数字的自辩？
2. 审查方程整洁度：常数是否打包成组合参数（Define σ ≡ … 的金牌做法）？
3. 我贴出推导后：逐步检查量纲、符号、极限行为（v→0、ρ→0、M→∞ 时是否退化到基准解析解）；
4. 若我 2 小时内推不动：提示我"第 14 小时检查点"规则——立即降级模型复杂度，评审宁可要完整闭环的简单模型，不要半成品复杂模型。
```

上下文包：题目原文 + 量级表 + 你的推导草稿。

## 3. 数值与验证（T4–T6）

> 第 14–38 小时用。验证三件套（收敛/极限/灵敏度）是金银牌分水岭，这里最值得花 AI 预算。

### 提示词：积分器与代码审查

```text
你是数值计算教练。审查我贴出的数值代码/方案，按 UPC 金牌论文的五要素清单：
1. 方法名 + 步长 + 初值 + 边界条件 + 终止条件，五要素是否齐全、是否都写进了论文的计划；
2. 先跑通一条轨迹再参数扫描——检查我是否本末倒置；
3. 代码分支是否讲得成物理事件（"当 h<H 时阻力与重力同时作用，否则只受重力"）；
4. 常见 bug 排查顺序：单位（90% 的量级错误是单位）→ 初值符号 → 坐标系手性 → 步长过大导致的伪收敛。
只审查不重写；每条问题给出最小修改建议。
```

上下文包：你的代码（关键循环）+ 《物理模型综述 08：方法论与数值算法总论》（可选）。

### 提示词：验证三件套设计与精度声明

```text
你是 UPC 金牌教练。我的主模型和数值方案如下。请设计验证三件套：
1. 收敛性：给出步长减半实验的具体做法，以及如何写成金牌论文那种精度声明（"Halving the step changes the exit speed in the fifth digit; we therefore claim 4–5 significant figures, worst case 4."的句式）；
2. 极限情形：选 1–2 个能让数值退化到解析基准的开关（关阻力、质量→∞、密度均匀化），说明退化对照怎么做；
3. 灵敏度：挑 2–3 个核心参数做 ±20% 扫描，建议输出形式（龙卷风图 / 区间表），并提醒：不确定度最大的参数要贯穿全文一致。
最后给我一段可直接放进论文的"误差与适用域声明"英文段落模板（含最坏情形点名）。
```

上下文包：主模型方程 + 数值方案；可选《写作句库》数值方法节。

## 4. 写作（T7–T8）

> 第 36–46 小时用。摘要最后写但必须带数值结论；逐节成文当天完成。

### 提示词：摘要打磨（数字ocracy）

```text
你是 UPC 金牌论文的英文编辑。这是我队的摘要草稿。按金牌标准逐句审查并改写：
1. 结构是否是：符号与关键定义 → 问题的两难（trade-off）→ 方法一句话 → 带区间/阈值/百分比的数值结论 → 建议与适用域；
2. 有没有至少一个硬数字（2010-A 金牌摘要直接给 8.8296° < θ < 8.8549°，允许误差 0.0253°）？没有数字的摘要在 UPC 等于没写；
3. 是否存在自夸词（accurate / great / obviously）——全部改成精度声明或引用式号；
4. 每句信息密度：删掉所有不承载信息的词。
输出：逐句批注表 + 改写后的完整摘要。
```

上下文包：摘要草稿 + 主要结果数字清单；强烈建议附《写作句库》摘要节。

### 提示词：逐节中译英与句式升级

```text
你是 UPC 金牌论文的英文编辑。把我贴的中文草稿译成论文英语，要求：
1. 使用本句库风格：信息密度高、自带逻辑连接词（Consequently / On the other hand / provided that / We conclude that）；
2. 每个数值陈述带单位与有效位数；每处近似给出理由；
3. 图表引用规范：每张图 "Figure N shows …" 且被正文点名；
4. 不用缩写不定义、不用 we believe 这类主观语，改为证据陈述。
输出：译文 + 你做了哪些风格决策的 3 条说明。
```

上下文包：中文草稿 + 《写作句库》对应章节。

## 5. 模拟评审（T9）

> 交卷前 2 小时用。评委只精读摘要与图题，三分钟定档。

### 提示词：评委三分钟模拟

```text
你是 UPC 评审，每年评审约百篇论文，平均给每篇摘要+图题 3 分钟。请严格按评审视角审查我贴的：标题、摘要、全部图题（论文其他部分不给）。
评分口径（UPC 评审不变量，按重要性排序）：
A 判据：模糊词是否全部操作化，阈值是否有自辩；
B 基准：是否有解析对照与回扣对比；
C 模型：主方程从基本定律出发、假设有量级论证、适用域明说；
D 验证：收敛/极限/灵敏度三件套是否可见（哪怕在图题里）；
E 呈现：图是否结论进图题、轴带单位、配色语义一致。
输出：① 5 分钟内你能否复述出 问题/判据/方法/主结果数字/结论——哪条复述不出；② 金/银/铜三档预判与理由；③ 交卷前最后 2 小时优先修的 3 件事。
```

上下文包：标题 + 摘要 + 全部图题（按顺序）；可选《提交前终检 checklist》。

## 6. 赛后复盘

> 比赛结束后 1–3 天内做，趁记忆还热。

### 提示词：结构化复盘访谈

```text
你是赛后复盘教练。UPC 比赛 48 小时已结束。请对我做结构化复盘访谈，一次只问一个问题，覆盖：
1. 时间线还原：各阶段（读题/基准/主模型/数值/验证/写作）实际用时 vs 计划（T0–T9），哪个阶段失衡；
2. 决策点回看：选题、降级模型、砍扩展项这三个决策现在评价对不对；
3. 失败模式归类：算不出来 / 算完了写不完 / 写完了没有验证，属于哪种（40 小时建模 8 小时写作是最常见死法）；
4. 下届可执行的 3 条改进，按"赛前能准备"与"赛中才遇到"分类。
收集完所有回答后，输出一页复盘纪要。
```
