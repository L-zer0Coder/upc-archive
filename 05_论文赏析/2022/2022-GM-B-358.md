# The Best Strategy for Penalty Kicks（2022 题B 队伍358）

**页数**: 24 页（正文约 18 页 + 代码附录约 6 页） ｜ **对应题目**: Problem B — FIFA Penalty Kicks（点球最优策略）

## 1. 论文速览

论文以空气动力学为核心建立旋转足球的飞行动力学模型：计入重力、浮力、空气阻力与 Magnus 力，导出矢量运动方程 (8) 并分解为三分量 ODE 组 (10)，用 Python（scipy `odeint`）数值求解，再把初速度方向转为球坐标角 $(\theta, \phi)$ 做参数扫描，得到能命中上角的瞄准角区间（$v_0=25$ m/s、$\vec\omega=15\vec k$ 时 $\theta\in[76.7°,79.8°]$，$\phi\in[75.5°,84.5°]$ 及 $[100.0°,110.5°]$）与最小初速 $v_{0min}=20.17$ m/s。第二问先给守门员建模（直立防守与扑救两种模式），用蒙特卡洛给出扑救成功率分布，再反向求出"绝对死角"（两块对称矩形），最终给出必进射门的角度区间 $\theta\in[76.95°,78.95°]$、$\phi\in[75.5°,75.9°]\cup[110.3°,110.6°]$。

## 2. 建模体系逐层拆解

**第一层：受力逐项推导（教科书级完整）。** 浮力式 (1) $\vec F_{float} = -\frac{4}{3}\pi r^3\rho_0\vec g$；阻力不用现成公式而现场推导：以球的最大截面圆盘为对象，两侧气流用 Bernoulli 原理式 (3) 得压差式 (4)、阻力式 (5)，再引入阻力系数 $C_a=0.4$（引 Carré et al. 关于足球缝线的气动论文）修正为矢量式 (6)；Magnus 力引 Kutta–Joukowski 定理得式 (7) $\vec F_m = -\frac{8}{3}\pi r^3\rho_0\,\vec\omega\times\vec v$，并以 Figure 5（文献图）解释旋转造成两侧流速差→压强差的机制。每一项都有"推导 + 文献"双重出处。

**关键修正：自转衰减的量级论证。** 3.1.4 节考虑切向摩擦使 $\frac{d\omega}{dt}=-k\omega$，解得 $\omega = \omega_0 e^{-kt}$；由 $k\propto r^3$、飞行时间小于 1 s，论证末角速度介于 $\omega_0$ 与 $0.999\omega_0$ 之间，故 $\omega$ 可视为常量——先考虑效应再用数量级正当舍弃，是全文最见功力的一小节。

**第二层：ODE 组与数值求解。** 运动方程 (8) 经分解 (9) 写成三个二阶 ODE (10)，含非线性阻力项 $-0.2\pi r^2\rho_0 v\vec v$ 与 Magnus 耦合项；无解析解，Python 数值积分。初速度方向用球坐标变换 (11) 参数化，固定 $v_0$ 与 $\vec\omega$ 扫掠 $(\theta,\phi)$ 判定球是否过门线且落在上角九宫格内。两组自转对照（$15\vec k$ vs $6\vec i+6\vec j+6\vec k$）显示斜轴自转使轨迹更不对称——对"旋转方向影响落点"给出了定量演示。

**第三层：守门员模型（几何 + 力学 + 概率）。** 人体参数全部取自文献：身高 1.90 m，肩心高 $h_l = h\cdot\frac{8-1-1/2}{8}=154.375$ cm、臂展等于身高故单臂 $l=0.95$ m（引 Sheppard《艺用解剖》）。直立防守：下蹲时间 $\sqrt{2h_l/g}=0.56$ s、起跳 0.90 m 耗时 0.43 s 均在 $t_{max}=0.65$ s 内可行，可达域为宽 $2l=1.9$ m 的全高矩形；扑救：由蹬地模型 (12) 解得 $F_N/m = 34$ m/s²、$t_0 = 0.181$ s，肩部轨迹为抛物线 (15)，扫掠起跳角 $\alpha$ 最大化覆盖面积积分 (16) 得 $\alpha=0.64$ rad、$x_t=3.235$ m，再沿轨迹法向偏移臂长插值出可达域。概率层面定义式 (17) $r(x,z)=n f_{xz}(x,z)$（$n$ 为可达域重叠次数、$f_{xz}$ 为二维正态），2 万次蒙特卡洛采样渲染成功率热图（Figure 15）。

**第四层：绝对死角。** 去掉时间限制重新优化得 $\alpha = 0.92$ rad，可达域并集与球门作差，解得死角边界交点 $(\pm2.84, 2.44)$、$(\pm3.66, 1.648)$，扣除球半径后仍是"足够大"的两块矩形；最后把死角反演回射门角度区间，与第一问闭环。

## 3. 数学方法与算法

数值方法为 scipy `odeint`（自适应步长 Runge–Kutta 类），角度搜索用网格遍历（$\theta$ 步长 0.1°、$\phi$ 步长 0.5°，见附录代码），最小初速用 0.01 m/s 步长扫描；概率分布用 $2\times10^4$ 点蒙特卡洛；面积最大化用 `fmin` 数值优化；守门员可达域用样条插值（`splrep`/`splev`）。参数来源明确（初速 $23.9\pm1.2$ m/s 引 Ravenscroft 实测）。不足：未报告 ODE 求解的收敛性/步长检验；上角判据为硬阈值几何判定，未做射门误差容差分析；概率模型中正态分布的方差取法（scale=7.32/2、1.22）缺乏论证。附录还暴露小的不一致：符号表取 $\rho_0=1.27$ kg/m³、$r=0.108$ m，而代码用 $\rho_0=1.29$、$r=0.11$；正文 $\alpha=0.64$ rad 与代码注释 0.673 rad 不一致（不确定何者为最终运行值）。

## 5. 获奖密码：为什么能拿金牌

1. **受力分析滴水不漏**：浮力、阻力、Magnus、自转衰减四项全考虑，且每项要么现场推导（Bernoulli 压差）要么给出文献系数（$C_a=0.4$、Kutta–Joukowski 式 (7)），模型完整性拉满。
2. **"先纳入、再量级舍弃"的规范操作**：自转衰减一节先解出 $\omega=\omega_0e^{-kt}$、再证明变化小于 0.1%，比直接假设 $\omega$ 恒定高一个论证层次。
3. **守门员建模的物理感**：把守门员当成"蹬地发力 + 抛体运动 + 臂长偏移"的力学对象，起跳角 $\alpha$ 通过面积积分 (16) 真优化，人体参数全部有解剖学出处，不是拍脑袋。
4. **从"概率小"到"必进"的递进策略**：先用重叠次数加权 + 蒙特卡洛给出风险分布，再求绝对死角，两个层次直接回答题目的"最佳策略"，且最后都折算回 $(\theta,\phi)$ 区间，与第一问首尾呼应。
5. **代码附录全公开**：三段 Python 让所有数值结果可复现，配合"参数均来自官方或公认数据"的声明，可信度高。

## 6. 可借鉴清单

1. 旋转球类问题按"重力+浮力+阻力+Magnus"四件套列式，Magnus 用 $\vec\omega\times\vec v$ 叉乘形式直接支持任意自转轴，代码通用性强。
2. 任何"想忽略的小效应"都先写出方程、再用数量级论证舍弃（如 $e^{-kt}>0.999$），一句话就能堵住评委的质疑。
3. 把初速度方向球坐标化为 $(\theta,\phi)$ 后做网格扫描，输出"可行角度区间"而非单点答案，更贴近"what velocities will result in a successful shot"的问法。
4. 对手/障碍物建模可用"可达域几何 + 时间约束 + 概率叠加"三层递进，最后用蒙特卡洛热图直观呈现风险地图。
5. 求绝对死角时记得**去掉时间限制重新优化**（本文 $\alpha$ 从 0.64 变为 0.92 rad），并扣除球体半径——细节决定结论可信度。
6. 人体工程参数（肩高、臂展、起跳高度）引用解剖学/运动科学文献，比自设数值更让生物力学类模型可信。
