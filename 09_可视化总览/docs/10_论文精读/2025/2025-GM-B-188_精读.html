1. 逐节导读

1.1 Abstract

它写了什么：三大模块声明（动态 ISA / Mach-Reynolds 阻力 / 2D+3D 动力学）→ 三类修正系数（Range/Altitude/Wind）→ "pre-calculated parameter correlation tables and linear interpolation"。 你要学什么：摘要用"模块清单"写方法——每个模块名即一个可检查的承诺。对比 155 队摘要给数值结论，188 队摘要给架构：两种风格都对，但开放题下"架构式摘要"更能撑起 69 页的体量感。

1.2 §3.1 Artillery type（历史定型节，全文最有味道的假设节）

它写了什么：三步论证弹种是 19 世纪中叶滑膛野战炮（年代排除线膛 → 球形+5 kg 排除长弹 → 11 cm≈4.33 in 吻合 9/12-Pounder，配图 M1857 拿破仑炮）；随后大段引出"实用仰角通常限于 0°–8°（直射）"的历史事实，宣布全文优先取 <10° 的低伸弹道但"不拒绝其他解"。 为什么这样写：这不是装饰性历史，而是解空间的预筛选：低伸弹道飞时短、风敏度低——这直接决定了后文军官方法只给 low-angle 表。460 队走得更远（直接把答案锁定在 5°–8° 走廊），207 队则按直射/间射双模式给表，三队同源不同深度。 你要学什么："According to related documents, the practical elevation range... was typically limited to a relatively narrow range between 0°...and about 5° to 8° of elevation"——用历史文献给解空间加先验，再声明" wouldn't reject other possible trajectories"保留完备性。假设节的最高境界是"假设即筛选，筛选即策略"。

1.3 §4.2 大气模型（式 4-4~4-7）

它写了什么：对流层 T=T₀+λY（λ=−0.0065 K/m）、ρ=ρ₀(T/T₀)^(−(g₀/Rλ)−1)（幂指数 4.256）、c₀=√(γRT)、Sutherland 黏度 μ=μ₀(T/T₀)^{3/2}(T₀+S)/(T+S)（S=110.4 K）。 为什么这样写：黏度是本队独有的零件——Re=ρVd/μ 需要它，而 Re 又是 Loth 公式的输入。零件环环相扣：ISA(T)→c₀→M；ISA(ρ,μ)→Re；(M,Re)→C_D。你可以批评 1200 m 弹道用不上这么细的大气，但不能批评它不自洽。 你要学什么：模型复杂度要被"下游输入"倒逼，而不是堆料。若阻力用常数 Cd（428 队），ISA 整节都可以删——428 队正是这么干的，两篇对照读，你会懂"复杂度守恒"。

1.4 §4.3 Loth 动态阻力系数（式 4-8~4-14）

它写了什么：F_D=½ρV²AC_D（4-8）、M=V/c₀（4-9）、Re=ρVd/μ（4-10），然后是核心的复合公式（4-11）：C_D = 24/Re·(1+0.15Re^{0.687})·H_M + 0.42C_M/(1+42500/Re^{1.16C_M}+G_M/Re^{0.5})，其中 H_M（亚/超声速两段多项式）、C_M（1.65+0.65tanh(4M−3.4) 等）、G_M（166M³+…20 / 5+40M⁻³）三个分段函数由式 (4-14) 给出，并加 C_D≥0.01 的数值下限。出处：Loth et al. 2021 AIAA Journal。 为什么这样写：常数 Cd（0.47）在 M≈1.33 出膛时低估一倍（Loth 给 ~0.98，见 §3 审计）——这是"必须用 Cd(M)"的定量理由，188 用一句 "accurately capture the severe drag variations experienced by the projectile during transonic and supersonic flight (up to 450 m/s)" 点题。 你要学什么：把复合公式拆成 Term1/Term2（式 4-12）再合成的写法——命名中间量是长公式的可读性技巧；同时注意 "The minimum drag coefficient is constrained such that C_D≥0.01 to ensure numerical stability"——给经验公式加数值护栏是工程素养。

1.5 §4.4–4.5 ODE 与数值实现（式 4-15~4-28）

它写了什么：状态向量 (x,y,vx,vy)（4-15）→ 定义阻力加速度因子 Φ=−ρAC_D V/(2m)（4-21）→ 方程塌缩成 (4-22) 的极简形式；3D 扩展加 (z,vz)（4-23~4-26）；初值（4-27）；事件函数 E=y−Y_initial（4-28）；求解器 ode113（Adams–Bashforth–Moulton 变阶多步法，RelTol 1e-9/AbsTol 1e-11）。 你要学什么：① Φ 因子与 155 队的 σ、428 队的 k(y) 同为"组合参数"手法，三篇对照；② 求解器要写名字——ode113 是多步法，对光滑右端项比 RK45 省一半函数调用，写出来就是品味；③ 事件函数用"返回初始高度"而非"落地"，因为炮和目标同高——终止条件的物理化表述（"signaling the end of the flight path"）。

1.6 §5.2 线性度检验（全文方法论之魂）

它写了什么：围绕标准工况 (V₀=400, X_std=1200, H_std=500) 对三个修正系数做线性检验：C_Z（侧风每 m/s 造成的侧偏）R²=1.000000、斜率 1.314 m/(m/s)；C_W（纵风角度修正）R²=0.997210、斜率 −0.011287°/(m/s)；C_H（高度修正）R²=0.814267、斜率 −0.0094°/HM——并解释 C_H 为何最弱（"the change in drag due to altitude is exponential, not linear"）。 为什么这样写：所有"查表+线性修正"方法都默认 Δθ=C·ΔX 可加线性。别的队默认，这队检验了。而且分级处理：R²≈1 的直接用常数，R²=0.8 的声明"acceptable for engineering approximations over a limited operational range"。 你要学什么：这是本篇最值得搬走的东西——给"线性化"本身做回归检验，三个 R² + 一段非必要性解释。哪怕只写一句 "R²=0.997 justifies treating C_W as a constant factor"，论文的科学性档次就不同。

1.7 §7.3 军官方法（式 7-3~7-8）

它写了什么：θ_final=θ_std+Δθ_total（7-3），Δθ_total=Δθ_X+Δθ_H+Δθ_W（7-4）；三步修正 Δθ_X=C_X(X_t−X_std)、Δθ_H=C_H·ΔH（ΔH 以百米计）、Δθ_W=C_W·W_X；侧风不改仰角而改横移 Z=C_Z·W_side（7-8，"aim the cannon laterally by the distance Z into the wind"）；心算例题：V₀=400 打 1300 m、800 m 高、5 m/s 逆风+10 m/s 横风 → 0.46−0.05+0.06=0.47°，θ_final=4.02°，Z=13.1 m。 你要学什么：纵风改仰角、横风改方位/横移的职责划分（207 队用密位、428 队用 mil 公式、460 队用 arctan，本队用"横移米数"）——四种表述一个物理。例题每一步都只剩乘法和加法，最后一句 "This procedure transforms complex ballistic computations into simple multiplication and addition" 可以直接抄进任何同类论文。

核心图复现——Loth Cd(M) 曲线与 θ–V₀ 双支（Fig 5-1 + Fig 5-4 的最小实现，常量对应式 (4-11)(4-14)）：

import numpy as np, matplotlib.pyplot as plt
from scipy.integrate import solve_ivp
from scipy.optimize import brentq

def isa(y):                       # 式(4-4)(4-5)(4-6)(4-7)
    y = max(y, 0.0)
    T = 288.15 - 0.0065*y
    rho = 1.225*(T/288.15)**(-(9.81/(287.05*-0.0065))-1)
    mu = 1.7894e-5*(T/288.15)**1.5*((288.15+110.4)/(T+110.4))
    return rho, np.sqrt(1.4*287.05*T), mu
def CD(v, y):                     # 式(4-11)(4-14): Loth 2021 复合公式
    rho, c0, mu = isa(y); M = v/c0; Re = rho*v*0.11/mu
    HM = 0.0239*M**3+0.212*M**2-0.074*M+1 if M < 1 else 0.93+1/(3.5+M**5)
    CM = 1.65+0.65*np.tanh(4*M-3.4) if M < 1.5 else 2.18-0.13*np.tanh(0.9*M-2.7)
    GM = 166*M**3+3.29*M**2-10.9*M+20 if M < 0.8 else 5+40*M**-3
    return max((24/Re)*(1+0.15*Re**0.687)*HM + 0.42*CM/(1+42500/Re**(1.16*CM)+GM/np.sqrt(Re)), 0.01)
k = lambda v, y: 0.5*isa(y)[0]*CD(v, y)*np.pi*(0.11/2)**2/5.0
def shoot(th_deg, v0):
    th = np.radians(th_deg)
    ev = lambda t, s: s[1]; ev.terminal, ev.direction = True, -1
    sol = solve_ivp(lambda t, s: [s[2], s[3], -k(np.hypot(*s[2:]), s[1]+500)*np.hypot(*s[2:])*s[2],
                                 -9.81 - k(np.hypot(*s[2:]), s[1]+500)*np.hypot(*s[2:])*s[3]],
                    [0, 60], [0, 0, v0*np.cos(th), v0*np.sin(th)], events=ev, rtol=1e-9, max_step=0.05)
    return sol.y_events[0][0][0] if sol.t_events[0].size else 0.0
def angle_lo(v0):
    ths = np.arange(0.2, 45, 0.5); prev = None
    for th in ths:
        val = shoot(th, v0) - 1200.0
        if prev and prev[1] < 0 <= val: return brentq(lambda a: shoot(a,v0)-1200, prev[0], th, xtol=1e-6)
        prev = (th, val)
fig, ax = plt.subplots(1, 2, figsize=(10, 4))
Ms = np.linspace(0.2, 2.0, 200)
ax[0].plot(Ms, [CD(M*np.sqrt(1.4*287.05*(288.15-0.0065*500)), 500) for M in Ms])
ax[0].set(xlabel='Mach number', ylabel='C_D', title='Loth C_D(M) at 500 m: transonic peak ~0.98\n(paper Fig 5-1; constant-C_D=0.5 misses it entirely)')
Vs = np.arange(150, 451, 15)
ax[1].plot(Vs, [angle_lo(v) for v in Vs], 'o-')
ax[1].set(xlabel='V0 (m/s)', ylabel='low-branch theta (deg)',
          title='theta_std,low vs V0 (X=1200 m): Loth refit gives 3.9 deg @450,\nvs paper 2.79 deg -- paper values match constant C_D~0.5 instead')
for a in ax: a.grid(alpha=.3)
plt.tight_layout(); plt.show()

复现结论写进了两条图题：①Loth 模型在 M≈1.05–1.3 处有 Cd≈0.98 的跨声速峰；②用该模型复算的低支射角（450 m/s→3.86°）与论文报告的 2.79° 不符——这是 §4 审计的核心证据。

3. 公式逐条精讲

3.1 真空基线（式 4-2、4-3）

$$\theta=\tfrac12\arcsin\!\Big(\frac{gx}{V_0^2}\Big)$$ - 怎么想到：同高抛体的射程 R=v₀²sin2θ/g 反解。论文用它给两个锚点：x=1200、V₀=450 → θ≈1.67°；θ=45° 时最小初速 V_min=√(gx)=√(9.81×1200)=108.50 m/s。 - ⚠ 审计：§4.1 写 108.50 m/s（正确），§5.1 又写 "free resistance model (108.44m/s)"——同文两个数，108.50 才对（108.44²=11719≠11772）。对照：496 队也写 108.44（同错），207 队未给此数。 - 数值感：真空角 1.67° vs 有阻力后 ~2.7–3.9°（取决于 Cd 模型）——阻力让射角几乎翻倍，这是所有队伍 Table 2 型对照表的共同结论。

3.2 ISA 大气链（式 4-4~4-7）

$$T=T_0+\lambda Y,\quad \rho=\rho_0\Big(\frac{T}{T_0}\Big)^{-(g_0/R\lambda)-1},\quad c_0=\sqrt{\gamma RT},\quad \mu=\mu_0\Big(\frac{T}{T_0}\Big)^{3/2}\frac{T_0+S}{T+S}$$ - 怎么想到：温度线性递减 + 静力学平衡 + 理想气体 → 密度的幂律（指数 −(g₀/Rλ)−1=4.256）；声速与黏度都只是温度的函数。 - 数值感：500 m 处 T=284.9 K、ρ≈1.167 kg/m³（海平面的 95.3%）、c₀≈338.0 m/s、μ≈1.80×10⁻⁵。弹道顶点 <100 m 时全部大气量的变化 <2%——这就是为什么本队的大气"高配"其实不影响结果（见 §4 审计）。 - 适用边界：幂律只在对流层（<11 km）成立；代码里对 >11 km 加了等温层的外推分支，虽用不上但写全了——"防御性编程"。

3.3 Loth 复合阻力公式（式 4-11~4-14）

$$C_D=\underbrace{\frac{24}{Re}(1+0.15Re^{0.687})H_M}_{\text{黏性项}}+\underbrace{\frac{0.42\,C_M}{1+42500/Re^{1.16C_M}+G_M/\sqrt{Re}}}_{\text{压差项}}$$ - 怎么想到：亚声速球阻力的经典 Schiller–Naumann 形式 24/Re·(1+0.15Re^{0.687}) 在跨声速会失效；Loth et al. (2021) 用三个马赫函数修补：H_M 乘在黏性项上修"可压缩黏性"，C_M 进入压差项分子定标"激波阻力平台"，G_M 出现在分母抑制低 Re 区的压差项。 - 完整推导（使用层面）：本文不推导（半经验公式无推导可言），但它做了极限检验：M→0 时 H_M→1、C_M→1.65+0.65tanh(−3.4)≈0.998、G_M→20——退化为标准球阻力公式 ✓；Re→10⁶ 高马赫时 C_D→0.42·C_M≈0.9–1.0，与超声速球实验平台一致 ✓。用极限行为背书经验公式，这是引用型公式的正确打开方式。 - 数值感（本文复算）：500 m 高度上 M=0.87→C_D≈0.75、M=1.16→0.95、M=1.33→0.98。出膛即峰、落地（233 m/s，M≈0.69）回 0.5 附近——450 m/s 档全程跨峰，常数 Cd 无从模拟。 - 适用边界：Loth 公式适用 Re≤10⁶、Ma 0.2–10（光滑球、无自旋）；Re 由 ρVd/μ 逐点算，所以 C_D 是位置+速度的二元函数，这是"动态 Cd"的含义。

3.4 阻力加速度因子 Φ（式 4-21、4-22）

$$\Phi=-\frac{\rho A C_D V}{2m}\ \Rightarrow\ \frac{d}{dt}\begin{pmatrix}x\\y\\v_x\\v_y\end{pmatrix}=\begin{pmatrix}v_x\\v_y\\\Phi v_x\\-g+\Phi v_y\end{pmatrix}$$ - 怎么想到：a_drag = F_D/m ·(−v̂) = −(ρAC_D/2m)·|v|·v⃗。把随时间变的标量打包成 Φ，方程只剩四行——与 155 队式 (4) 的 0.235πr²ρ₀、428 队式 (16) 的 k(y) 三篇同构，可对照记忆。 - 数值感：Φ(450 m/s, 500 m) = −0.5×1.167×0.978×9.5e-3/5×450 ≈ −0.49 s⁻¹，即速度衰减时间尺度 ~2 s（低角 3.8 s 飞行内损失一半速率，与落点 233 m/s 一致，见 428 队同型数据）。

3.5 线性修正族（式 7-3~7-8）

$$\theta_{final}=\theta_{std}+\underbrace{C_X\Delta X}_{\text{射程}}+\underbrace{C_H\Delta H}_{\text{海拔}}+\underbrace{C_W W_X}_{\text{纵风}},\qquad Z=C_Z W_{side}$$ - 怎么想到：在标准点做一阶 Taylor 展开：θ(X,H,W)≈θ_std+θ_X·ΔX+θ_H·ΔH+θ_W·W。三个斜率 C 就是偏导数的数值版；§5.2 的 R² 检验回答"一阶展开在 ±多少范围内够用"。 - 数值感：C_X(400)=0.00456°/m → 每 100 m 射程 +0.46°；C_W(400)=−0.0117°/(m/s) → 5 m/s 逆风 +0.06°；C_Z=1.314 m/(m/s) → 10 m/s 侧风 13.1 m 横移。量级排序：射程差 ≫ 海拔 > 纵风 ≫ 横风（角度上）——军官的注意力应按这个顺序分配。 - ⚠ 审计：① §5.2.3 的斜率 −0.0094°/HM 与附录 Table 1 的 C_h,low(400)=−0.016932 °/hm 差 80%，心算例题用的是后者；② §5.2.2 斜率 −0.011287 与附录 C_w,low(400)=−0.011747 差 4%。正文检验值与附录交付值不同源，引用时要选一个。

独立复现审计汇总（Python+scipy，复算 Loth 模型与其对照）： - ⚠ 重大疑点：论文交付数值与 Loth 模型不符，与常数 Cd≈0.5 模型吻合。 复算 Loth：θ_std,low = 6.83/5.48/4.56/3.86°（V₀=300/350/400/450）；论文：6.15/4.59/3.55/2.79°；而常数 Cd=0.5 复算给 6.21/4.54/3.47/2.74°，与论文几乎逐点吻合。射表交叉验证：论文 Table 2 (400 m/s, 3°)→1076 m，Loth 复算 925 m，常数 0.47 复算 1113 m——同样倒向常数模型。 - vmin：Loth 复算 ≈143 m/s，论文 142.06 m/s ✓（低马赫区 Loth≈常数 Cd，无法区分，此项相容）。 - 修正系数心算例题内部算术自洽 ✓（0.46−0.05+0.06=0.47，θ_final=4.02 ✓），但 ⚠ C_H 正文斜率（−0.0094）与附录（−0.0169）差 80%；C_W 两处差 4%。 - ⚠ §4.1 说真空 vmin=108.50，§5.1 又引 108.44，前者正确。 - 另一处工艺问题：式 (7-1) 把阻力写成 "C_d=½C_dρV²A"（左端应为 F_D），符号笔误。 - 值得肯定：附录代码含 AI 辅助声明脚注（"Generative AI Assisted Coding on program framework...Algorithms...are not included"），这是合规披露的范本。

总评：物理叙事（ISA+Loth+线性度检验）是十三篇里最完整的，但"所述模型"与"所出数据"脱节——大概率是最终数值由某版常数 Cd 代码生成后未随模型升级同步。教训：模型升级后必须重跑全部交付表，并保留一张"模型版本-数据版本"对照。
