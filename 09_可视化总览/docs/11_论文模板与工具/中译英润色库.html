中译英润色库 —— 从中文草稿到金牌论文英语

用法：写完中文草稿（或直接用英文写卡壳时），按本库五步润色法逐段处理；句式卡壳查 §2 对照表与《写作句库》，词穷查 §3 升级表，拿不准频率与地道程度看 §7 语料实证（全部统计自 74 篇金牌论文原文）。最后必读 §6 诚实表述——包括官方对 AI 使用披露的硬性要求。

0. 五步润色法（每段过一遍）

  1. 拆：中文一句话常塞三层逻辑；英文按"一句一个动作"拆开，用连接词（Consequently / On the other hand / provided that）把逻辑摆在句面上。金牌句子的共同点是"自带路标"（见《写作句库》§8）。
  2. 立：第一句先立判据或定义（"We define … as …"，金牌语料 13 篇；"We set …"，26 篇）。中文习惯铺垫后再定义，英文论文反过来。
  3. 升：动词升级（§3 表）：把"进行分析/进行计算/考虑了"换成 quantify / compute / account for；把"很大/很小"换成具体量级（three orders of magnitude / within 2%）。
  4. 装：数字装进句子里——每个结论句必须带 数值 + 单位 + 有效位数 或 区间（"8.8296° < θ < 8.8549°"）。没有数字的段落八成还没算完。
  5. 诚：对照 §6 检查有没有自夸词、跳步词、无出处断言；假设给量级自辩，忽略项写一行数字封存；用了 AI 按官方格式披露。

1. 时态与语态规范（UPC 论文惯例）

部位 时态 例句
摘要（做什么/发现什么） 一般现在时为主 "We investigate the aerobraking maneuver … We conclude that …"
方法与计算过程 一般过去时 "The equations of motion were numerically integrated using Euler's method."
图表指向 一般现在时 "Figure 1 shows a trajectory with θ = 8.83°."
模型假设（普适事实） 一般现在时 "The atmospheric density decreases exponentially with altitude."
结论与建议 现在时 + 情态动词 "We would advise against relying on this maneuver."
  • 语态：方法段惯用被动（"were integrated / was approximated"），论证段用主动第一人称（"We conclude / We find"）——金牌论文不回避 we，语料中 "we assume" 出现 166 次（44/74 篇）、"we obtain" 82 次、"we conclude" 30 次。
  • 中文里"本文/笔者/作者"不要译成 "this paper thinks / the author"，一律用 we（单职工队也用 we）。

4. 分部位词汇补充（配合《写作句库》的句式使用）

  • 定义与判据：define … as / we call this … / take … to be / refer to … as；判据词：criterion (pl. criteria)、threshold、margin、tolerance、cut-off。
  • 假设：idealize / idealized model / point mass / rigid body / steady-state / quasi-static / uniform / isotropic / inviscid / adiabatic。
  • 数值：discretize / time step Δt / step size / integrator / RK4(Runge-Kutta) / stiff / tolerance / convergence / mesh / grid resolution。
  • 验证：convergence test / limiting case / degenerate to / recover（数值退化到解析解用 recover）/ benchmark / anchor / cross-validate / sensitivity sweep。
  • 误差：error propagation / uncertainty of order … / worst-case / effective digits / significant figures / rounding。
  • 图表：plot / profile（沿轨迹的分布图）/ phase portrait / heat map / inset（图内小图）/ caption / legend / equal aspect / dashed line（虚线表对照/基准）。
  • 结论：takeaway（少用口语）/ takeaway 只在备忘；论文用 the main result is … / the practical implication is …。

5. 数字、单位与精度表述

  • 数字与单位之间加空格（30 km/s），单位用正体；数值范围用 en-dash（8.8296°–8.8549°）或不等式。
  • 精度声明模板（语料实证见 §7 significant figures / margin of error）："Halving the step changes the exit speed in the fifth digit; we therefore claim 4–5 significant figures, worst case 4."
  • 量级表达：on the order of 10³ km / O(10⁻⁴)；"相差三个数量级" = differs by three orders of magnitude。
  • 百分比：a 20% reduction / reduced by 20%（别写 reduce 20%）。
  • 中文"万/亿"换算成科学计数法（10⁴ / 10⁸），不要写 10000 km。

6. 诚实表述（评审最看重，也含官方硬规定）

  1. 不自夸：accurate / great / perfect → 换成精度声明或对照数据。
  2. 不跳步：obviously / clearly / it is easy to show → 补一步推导或引用式号。
  3. 承认不确定：每个关键数字后面跟 uncertainties 或 ±区间；最坏情形定全程精度。
  4. 局限具体化：limitation 不是道歉，是给评审看你知道边界（"模型在 h < 70 km 内有效"）。
  5. 负结论也是结论："As Δθ is so small, we would advise against relying on this maneuver."——论证扎实的"不建议"是高分项。
  6. AI 披露（官方规定，2026 规则原文要求）：若使用生成式 AI，论文末尾必须有 "Report on the Use of AI" 一节：①所用系统 ②逐条原始提问 ③完整输出。含抄袭或虚假内容将严重扣分。建议把 AI 限定为教练用途（审查、提问、教学），写作保持本人执笔。

8. 反面清单（与《写作句库》§9 互补）

  1. ❌ "We use a very accurate model" —— 自夸无证据。
  2. ❌ "Obviously, the answer is …" —— 评委不觉得 obvious。
  3. ❌ 摘要无数字 —— 在 UPC 等于没写摘要。
  4. ❌ "as shown below" —— 每张图必须编号并被正文点名。
  5. ❌ 中式排比与四字格直译（"综上所述、总而言之、众所周知"→ It is well known 其实也是禁语，除非带引用）。
  6. ❌ "It is well known that …" 无引用 —— 要么给文献，要么改成 "As a standard result [n], …"。
  7. ❌ 单位缺失或用中文单位制习惯（万 km、亿 kg）。
  8. ❌ 隐瞒 AI 使用 —— 官方规定必须披露，详见 §6.6。
