术语速查表（中译统一口径 + 常见异译对照）

本文定位：全库 235 份文档的中译术语口径表——写解读 / 赏析 / 精读 / 论文时，同一概念用同一译名；扫描某篇英文材料时，用它反查概念。每词三栏：首选译名（库内统一用）、常见异译（读到别家材料时会遇到，不采用）、一句话（够用的理解粒度）。按物理域分组，域的划分与《08_物理模型综述》一致。

用法：① 写作卡壳时查首选译名；② 读英文论文遇生词按字母扫表；③ 发现库内某篇译名与本表冲突——以本表为准并提 issue，巡检时统一修正。术语后有 (n/73) 式标注的表示该概念在赏析语料中的出现规模，供辨识常用度。

1. 航天与轨道动力学

英文 首选译名 常见异译 一句话
aerobraking 气动制动 大气制动、空气刹车 反复穿越行星上层大气靠阻力降轨，省燃料但耗时间
aerocapture 气动捕获 大气捕获 一次深穿大气把双曲线轨道直接压成环绕轨道，比气动制动更激进
delta-v (Δv) 速度增量 德尔塔-V 轨道机动的"货币"，火箭方程里唯一需要攒的量
gravity assist / slingshot 引力辅助 引力弹弓、借力飞行 借行星的动量改向加速，能量守恒角度是"偷"行星一点点速度
Hohmann transfer 霍曼转移 霍曼变轨 两圆轨道间最省 Δv 的双切椭圆转移
vis-viva equation 活力公式 活力积分 轨道上任意点 v² = μ(2/r − 1/a)，动能与引力势能的轨道版账本
Tsiolkovsky rocket equation 齐奥尔科夫斯基火箭方程 火箭方程 Δv = v_e·ln(m₀/m_f)，一切推进方案的死刑判决书
specific impulse (Isp) 比冲 比推力 推进剂效率，单位推进剂流量换多少冲量
periapsis / apoapsis 近拱点 / 远拱点 近地点、近心点（绕地时） 椭圆轨道距焦点最近 / 最远点
bi-elliptic transfer 双椭圆转移 三冲量变轨 大轨道比变化时比霍曼更省 Δv 的绕远方案
escape velocity 逃逸速度 第二宇宙速度 摆脱引力井的最低初速，√(2μ/r)
sphere of influence 引力影响球 作用球 行星引力主导 vs 太阳主导的分界，分段积分的接缝
ballistic capture 弹道捕获 低能转移 借太阳-行星系统三体效应零耗捕获（如 Hiten）
trajectory injection 入轨 轨道注入 主动段结束进入预定轨道的动作
drag make-up 阻力补偿 — 低轨卫星抵消大气阻力的定期抬轨
aerodynamic heating 气动加热 再入烧蚀热 高速穿越大气时激波与摩擦带来的热流，驻点最烈

2. 流体与空气动力学

英文 首选译名 常见异译 一句话
drag / lift 阻力 / 升力 曳力 与速度反向 / 垂直的气动力两个分量
dynamic pressure 动压 速压 ½ρv²，载荷与过载估算的通用量
magnus effect 马格努斯效应 麦格纳斯效应 旋转让球两侧流速不对称产生侧向力，曲线球的来源
Reynolds number 雷诺数 — 惯性与黏性之比，决定流态层流/湍流
boundary layer 边界层 附面层 壁面附近速度从 0 过渡到主流的薄层
flow separation 流动分离 气流分离 逆压梯度把边界层推离壁面，阻力骤增的元凶
drag coefficient (Cd) 阻力系数 阻力因数 无量纲阻力归一化，球的凹坑就是为压它
terminal velocity 终末速度 收尾速度 阻力=重力时的稳定下落速度
stagnation point 驻点 滞止点 迎流面上速度归零、压力最大的点
Prandtl number 普朗特数 — 动量扩散与热扩散之比
compressible / incompressible 可压缩 / 不可压缩 — Ma < 0.3 常按不可压缩处理
Mach number 马赫数 — v/a，跨声速区气动特性剧变

3. 刚体与多体动力学

英文 首选译名 常见异译 一句话
moment of inertia 转动惯量 惯性矩 旋转的"质量"，I = ∫r²dm
angular momentum 角动量 动量矩 守恒律主角，冰舞收臂加速的原理
torque 力矩 转矩、扭矩 角动量变化率
precession 进动 旋进 自转轴绕第三轴的慢锥转，陀螺与地球都玩
gyroscope stability 陀螺定轴性 陀螺稳定 高自旋角动量抵抗姿态扰动
center of mass / of percussion 质心 / 撞击中心 打击中心 挥棒不震手的击点
two-body problem 二体问题 — 有解析解；加一体就得数值积分
restricted three-body 限制性三体 — 第三体质量可忽略的特例，拉格朗日点的家
Lagrange point 拉格朗日点 平动点 两体旋转系里五个共转平衡点，L1/L2 是望远镜之家
nutation 章动 — 叠在进动上的小"点头"

4. 热学与能量输运

英文 首选译名 常见异译 一句话
Stefan–Boltzmann law 斯特藩–玻尔兹曼定律 史蒂芬-波兹曼定律 P = εσT⁴，辐射散热的总闸门
albedo 反照率 反射率 行星把阳光弹回去的比例
blackbody 黑体 绝对黑体 吸收一切入射辐射的理想辐射体
emissivity 发射率 辐射系数 实际物体相对黑体的打折系数 ε≤1
thermal equilibrium 热平衡 — 吸收=辐射时的温度，行星与航天器都先算它
radiative cooling / radiator 辐射散热 / 辐射器 散热板 真空里唯一能用的散热方式
conduction / convection 传导 / 对流 — 介质里 / 随介质搬运的热输运
heat flux 热流密度 热通量 单位面积功率 W/m²，再入与驻点计算的主角
adiabatic process 绝热过程 — 不换热只做功，大气温度直减率的来源
thermal inertia 热惯量 — 表面温度响应迟钝程度，昼夜温差的调节器

5. 生物物理与标度律

英文 首选译名 常见异译 一句话
allometric scaling 异速标度 比例标度 生理量随体重按幂律 Y∝M^b 缩放
Kleiber's law 克莱伯定律 — 代谢率 ∝ M^(3/4)，跨 20 个数量级仍成立
square-cube law 平方-立方定律 平方立方反比 面积∝L²、体积∝L³，体型上限的物理根
bone strength 骨强度 — 骨骼承压 ∝ 截面积，恐龙为何不能无限大
metabolic rate 代谢率 新陈代谢率 单位时间生物耗能功率
stride frequency / Froude number 步频 / 弗劳德数 — 步行-奔跑转换的无量纲速度
population growth 种群增长 — 指数/逻辑斯蒂模型，资源约束下的 S 形
biomechanics 生物力学 — 用力学解剖运动，恐龙步速、蹦床都靠它

6. 电磁与辐射

英文 首选译名 常见异译 一句话
radiation dose 辐射剂量 — 吸收剂量 Gy 与当量剂量 Sv，别混用
absorbed dose / dose equivalent 吸收剂量 / 当量剂量 — 物理沉积 / 乘品质因子后的生物学账
inverse-square law 平方反比律 反平方定律 点源强度随距离 1/r² 衰减，屏蔽距离都是它
half-value layer (HVL) 半值层 半减弱层 把辐射强度砍半的屏蔽厚度，屏蔽估算的算术捷径
solar sail 太阳帆 光帆 光压持续推进的无燃料推进（与激光光帆区分）
magnetic shielding 磁屏蔽 — 用磁场偏转带电粒子，火星辐射题的热门方案
galactic cosmic ray (GCR) 银河宇宙线 银河宇宙射线 高能质子为主，屏蔽极难，深空剂量的底盘
solar particle event (SPE) 太阳粒子事件 太阳质子事件 耀斑期间的短时强辐射，应急屏蔽的对象
ionizing radiation 电离辐射 — 能打出离子的辐射，生物损伤的分界线
Lorentz force 洛伦兹力 罗伦兹力 qv×B，带电粒子在磁场里拐弯的唯一原因

7. 声学与信号处理

英文 首选译名 常见异译 一句话
sound pressure level (SPL) 声压级 声压位准 20·log₁₀(p/p₀) dB，p₀=20 µPa
formant 共振峰 峰值频率 声道共振抬起来的频谱包络峰，音色的身份证
frequency response 频率响应 频响 系统对每个频率的增益/相位账单
harmonic / overtone 谐波 / 泛音 — 整数倍 / 非严格整数倍的高频成分
total harmonic distortion (THD) 总谐波失真 — 谐波能量占比，"保真"题的量化判据
Doppler effect 多普勒效应 都卜勒效应 相对运动造成的频率搬移
acoustic impedance 声阻抗 — ρc，界面反射/透射的账本
reverberation 混响 残响 反射声的拖尾，房间音质的主角
signal-to-noise ratio (SNR) 信噪比 讯噪比 有用信号与噪声的功率比
Fourier transform / FFT 傅里叶变换 / 快速傅里叶变换 傅立叶变换 时域↔频域的总闸门，频谱分析的发动机

8. 方法论与数值算法（通用）

英文 首选译名 常见异译 一句话
order-of-magnitude estimate 量级估算 费米估算 只答 10 的几次幂，建模前的侦察兵
dimensional analysis 量纲分析 因次分析 用量纲齐次性直接猜公式结构
figure of merit 品质因数 性能指标 把多目标压成一个可比标量
Euler method 欧拉法 尤拉法 最朴素的步进积分，够用但要报步长收敛
Runge–Kutta (RK4) 龙格-库塔法 龙格库塔 四阶精度积分器，轨道与弹道的主力
convergence test 收敛性检验 收敛测试 步长减半看答案动不动，验证三件套之一
sensitivity analysis 灵敏度分析 敏感度分析 参数扫描看结论稳不稳，验证三件套之三
sanity check 合理性检验 — 与已知锚点（实测/解析解）对表，验证三件套之二
Monte Carlo method 蒙特卡洛方法 蒙地卡罗法 随机抽样把不确定性变成分布
Poisson process 泊松过程 — 稀有随机事件计数模型（撞击概率题常客）
truncation / rounding error 截断误差 / 舍入误差 — 数值误差两大来源，前者是方法、后者是机器
normalization 归一化 规范化 去量纲/缩放，让不同方案可比
criterion (judging criterion) 判据 判定标准 模糊词的量化替身，立判据是建模第一步
first-principles model 第一性原理模型 从原理出发的模型 从基本定律推而不是从数据拟合
fit / overfitting 拟合 / 过拟合 — 参数贴数据；贴过头就丢了物理
deliverable 交付物 可交付成果 每个阶段的"能拿得出手的东西"
design of experiments (DOE) 实验设计 — 系统地选参数点，别瞎扫
