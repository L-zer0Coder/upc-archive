Analysis of the optimal initial velocities and spins of soccer in Penalty Kicks（2022 题B 队伍480）

页数: 约 15 页 ｜ 对应题目: Problem B — FIFA Penalty Kicks（点球最优策略）

1. 论文速览

本文最大的特色是把"旋转轴"解放出来：不作"只绕竖直轴旋转"的常见简化，令 $\vec\omega = (\omega_{0x},\omega_{0y},\omega_{0z})e^{-\mu t}$ 任意方向且随时间指数衰减，导出含衰减 Magnus 项的全三维非线性 ODE 组 (7)，数值枚举后得到 600 多组能命中上角的 $(\vec v_0, \vec\omega_0)$ 组合，并用"点大小=速度、点颜色=偏角、框颜色=仰角"的六维数据三维可视化呈现（Figure 5–6、Table 1 给出各速度档的参数上下界）。第二问在"守门员总能正确判断且即时反应"的最坏假设下只考虑防守面积，用蹬地-斜抛模型求最大控制域（$s_{max} = 13.34$ m²，$\alpha = 57.52°$），随后用一个漂亮的反转论证（鲁棒性 + 2002–2018 世界杯统计）主张射下角优于上角，最终给出最优踢法 $v_0 = 21.245$ m/s、仰角 0.2057 rad、方位角 1.4182 rad、自转 15.255 rad/s（Table 3）。

2. 建模体系逐层拆解

第一层：球的多轴旋转动力学。 Magnus 力直接采用矢量叉乘形式 (1) $f = \frac{8}{3}\pi\rho r^3\,\vec\omega\times\vec V$；阻力取 $\vec R = -kV^2\hat V = -kV\vec V$（式 6），$k = \frac{\pi}{2}c\rho r^2$（$c=0.5$）。关键一步是自转衰减模型：假设空气阻力矩正比于角速度（假设 3），写出道具方程 (2) $\vec M = I\frac{d\vec\omega}{dt} = -\eta\vec\omega$，分量式 (3)，解得 (4) $\vec\omega = \vec\omega_0 e^{-\mu t}$，$\mu = \eta/I$——与 358 的"量级论证后忽略"、471 的"后期修正"都不同，480 是从一开始就把衰减放进方程，代入式 (5) 使 Magnus 项带 $e^{-\mu t}$ 因子。最终动力学方程组 (7) 是含时变系数的三个二阶 ODE（注：式 (7) 第三行左端误印为 $mx''$，应为 $mz''$）。

第二层：解空间枚举与约束设定。 声明式 (7) 无解析解，按人体能力限 $v_0 \le 31$ m/s；分量初速取 $x: 0\sim11$、$y: 20\sim30$、$z: 0\sim10$ m/s，角速度 $x: -8\sim8$、$y: -5\sim5$、$z: 0\sim15$ rad/s（称参考了大量弧线球论文与比赛视频）；"上角"定义为距横梁-立柱角点 1–2 倍球半径的环带（附录代码 range = [a, 2*a]，判据为过门线平面 $y\in[10.9, 11.1]$ 时的 $x, z$ 落带内）。整数网格枚举得 600+ 组成功解，Table 1 按 $v_0$ 分档给出 $\theta_v, \varphi_v, w_0, \theta_w, \varphi_w$ 的 max/min。

第三层：守门员最大防守域。 明确列出影响扑救的三因素（判断方向、防守面积、起动时机）后，取最坏情形——判断全对、反应为零，只剩面积问题。人体参数：身高 185 cm、臂展≈身高、头长为身高 1/8 → 臂长 69.5 cm；起跳 $V_0 = \sqrt{2gh} = 4.43$ m/s（式 8，$h=1$ m），蹬地距离 $S_a = 40$ cm 解出 $a = 34.33$ m/s²、$t_a = 0.181$ s（式 9–10），与 358 的数字完全一致（两队用了同一类蹬地模型）。斜蹬角 $\alpha$ 下由 $\tan\beta = \frac{a\sin\alpha - g}{a\cos\alpha}$（式 11）与位移式 (14)(15)（先匀加速后自由体）积分得可达面积 $s$，对 $\alpha$ 求极值：$s_{max} = 13.34$ m²、$V_x = 3.34$ m/s、$V_y = 3.47$ m/s、$\alpha = 57.52°$。控制域合成"椭球状"三维防守区（Figure 8），结论指向四个角。

第四层：上角 vs 下角的策略反转（本文亮点）。 三条独立证据：其一，鲁棒性检验——以上角区域中心解为初值，上下扰动 2 m/s 或 2 rad/s，统计仍能命中的比例，下角容差显著更大（Figure 9）；其二，世界杯 2002–2018 实测数据（Table 2）：下左角进球率 82.95%、射失率仅 2.79%，上左角进球率虽 83.53% 但射失/中框合计 16.3%；其三，上角对体力与心理要求更高。据此把第二问的目标区改设为下角，重解得最优踢法 Table 3，并展示射向下左角的轨迹（Figure 10，另一侧对称）。

3. 数学方法与算法

纯数值路线：MATLAB 显式 Euler 积分（$dt = 0.0001$ s，$t\in[0,1]$ s），六重循环整数网格枚举（附录代码），成功判据为穿越 $y\in[10.9,11.1]$ 平面时落点处于角点环带。数据呈现方法是全文最出彩之处：把 $(w_0, \theta_w, \varphi_w)$ 放入三维坐标系，用点大小编码 $v_0$、点颜色编码速度偏角、外框颜色编码速度仰角，实现六维数据在三维图中的可视化（Figure 5–6），作者在 Strengths 中也自评此点。灵敏度方面做了扰动 ±2 单位的鲁棒性计数（Figure 9），但未做系统灵敏度分析；$\mu$ 在代码中硬编码为 0.1（注释 $\mu = \eta/I$，按 $\eta = 18.1\times10^{-6}$、$I = \frac{2}{5}ma^2$ 计算实际约 0.009，不一致——不确定作者是否有意放大衰减效应）；附录主程序空气密度用 1.29 而绘图函数用 1.205，两处不一致；式 (6) 要求阻力恒与速度反向，但代码 $z$ 方向阻力项按 $v_z$ 正负切换符号，与式 (6) 不符（疑似笔误，好在数值影响有限）。

5. 获奖密码：为什么能拿金牌

  1. 多轴旋转 + 自转衰减一步到位：$\vec\omega(t) = \vec\omega_0 e^{-\mu t}$ 的任意轴建模（式 4–5）比"只绕 z 轴"的简化更接近真实香蕉球，作者在 Strengths 中明确把这一点与"common theory"对标。
  2. 六维数据可视化：用点尺寸/点色/框色把 $(v_0,\theta_v,\varphi_v,w_0,\theta_w,\varphi_w)$ 压缩进一张三维图，解决了"参数太多讲不清"的呈现难题，是评委容易记住的独创性工作。
  3. 结论敢于反转题目预设：题目引导射上角，本文用鲁棒性检验 + 世界杯 16 年真实数据（Table 2）+ 风险论证三条证据主张下角更优——把"最优策略"答成了超越题面的决策建议，体现物理建模的判断力。
  4. 最坏情形假设的清晰逻辑：第二问开头即声明"三因素中假设判断与反应完美，只剩面积"，把难以量化的人类因素隔离掉，建模边界干净。
  5. 守门员优化有完整推导链：蹬地模型 (8)–(10) → 斜抛几何 (11)–(15) → 面积积分求极值（$\alpha = 57.52°$、$s = 13.34$ m²），与 358 的 $\alpha$ 优化异曲同工且给出面积目标函数。

6. 可借鉴清单

  1. 旋转球建模保留 $\vec\omega$ 的三分量与叉乘形式，并直接写入衰减因子 $e^{-\mu t}$，代码只需多三个状态量即可支持任意旋转轴。
  2. 参数结果多时，学习其六维→三维映射可视化（大小、颜色、边框各编码一维），一张图讲清整个解空间。
  3. 给"命中区域"下操作性定义（本文：角点外 1–2 倍球半径环带），比模糊的"上角"更可计算，也方便做容差分析。
  4. 用扰动重采样（±2 m/s、±2 rad/s 数命中数）代替复杂的误差传播，快速评估策略鲁棒性。
  5. 用真实赛事统计表（进球/射失/被扑/中框分列）为模型结论背书，体育类赛题尤其有效。
  6. 写清"哪几个因素被假设掉、为什么"（三因素保留一个），再最强的对手模型也讲得通——这是处理含人的系统时的通用套路。
