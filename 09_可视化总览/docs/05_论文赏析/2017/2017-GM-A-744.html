SOLAR SALES ON YOUR TRIP TO MARS（2017 题A 队伍744）

页数: 34 页 ｜ 对应题目: 太阳帆飞往火星（Solar Sailing to Mars）

1. 论文速览

巴塞罗那自治大学队伍是本批次篇幅最长、物理最"重"的一篇。以对数螺旋轨迹为解析骨架，用完整非理想太阳帆 SRP 模型（含吸收、漫反射、再辐射系数）建立极坐标运动方程，RK4 数值积分 + SciPy 的 SLSQP 非线性规划求解"最小帆面积 × 最短时间"双目标 NLP；帆角 $\alpha(t)$ 离散为 $n$ 段常值并做分区收敛检验。主线结果：500 天、最小帆面积 183158 m²、最大载荷 718 kg（ARV 8.31 km/s）；进一步放开"发射日期"约束得火星应超前地球 1.14 rad（65.38°）发射，帆面积降至 145950 m²、载荷 978 kg；还把模型推广到火星→地球反向转移（0.24 km²、499.98 天）。

2. 建模体系逐层拆解

  • 背景层（第 2 节）：先讲 Hohmann 转移（附录 A 推导式 31–33）与引力甩摆，Table 1 引用文献对比 Hohmann（259 天、$\Delta v_T=5.59$ km/s）与不同 $\beta$ 下对数螺旋的时间/速度增量——既展示知识面，又为"帆方案 Δv 优势"埋下伏笔。
  • 解析层：固定螺距角的对数螺旋解式 (3) $r(\theta)=r_0\exp(\theta\tan\gamma)$，速度式 (4) $v(r)=\sqrt{\frac{\mu}{r}\left[1-\beta\cos^2\alpha(\cos\alpha-\sin\alpha\tan\gamma)\right]}$，并指出帆速恒小于当地圆轨道速度、两端需速度不连续；螺距角与螺旋角的隐式关系式 (5) 给出最优 pitch 角的定义。
  • 非理想 SRP 模型（核心深度所在）：理想反射力式 (8)；再依次引入反射系数 $\rho$、镜面因子 $s$（式 9）、吸收（式 10）、漫反射 $B_f$（式 11）、前后表面再辐射 $\epsilon_f,\epsilon_b$ 及比例 $r_f,r_b$（式 12–14），合成为标准三系数形式式 (15)–(16)： $$\vec F_{SRP}=2PA\cos\alpha\,(b_1\hat r+(b_2\cos\alpha+b_3)\vec n),\quad b_2=\rho s,\ b_3=\tfrac12\big[B_f\rho(1-s)+(1-\rho)\tfrac{\epsilon_fB_f-\epsilon_bB_b}{\epsilon_f+\epsilon_b}\big]$$ 取 $b_1=0.0864,\ b_2=0.8277,\ b_3=-5.43\times10^{-3}$（引自文献 [9]），这是三篇 2017-A 中唯一超出"理想镜面"的队伍。
  • 数值层：状态向量 $\vec x=(r,\theta,u,v)$，全方程组式 (21)；假设清单明确（圆轨道、二维、球体、忽略行星引力与大气的适用范围、到达判据为距行星中心 < 行星半径、初始相对速度 ≤ 逃逸速度等九条）。

3. 数学方法与算法

RK4（SciPy dopri5，步长 1/500 小时）+ SLSQP。把"到达"写成罚函数式 (24) $f=\max(D_p-R,0)+\max(D_v-V,0)$，再扩为目标式 (25) $g=k_1\max(D_p-R,0)+k_2\max(D_v-V,0)+k_3t_f+k_4A$，权重意义与"变量量纲差异导致 $k_1,k_2$ 数值上更小"都有解释（式 30 给出实际取值）。方法上最出彩的是三重检验：(1) 分区收敛——Table 2 显示 $n=10,15,20,25,30$ 段结果都稳定在 498–519 天、ARV 7.1–8.6 km/s，Table 3 进一步显示 1、2、3 段几乎同样好，说明"无需频繁调姿"；(2) 稳定性——多组初值重复优化得到相同轨迹形态；(3) 权重灵敏度——Table 4 的面积—时间—载荷权衡表，并发现面积超过 200000 m² 反而因 ARV 约束被迫绕远路。缺陷也被记录：Earth→Jupiter 算例因 Python 浮点溢出失败，作者给出改单位或换 C++ 的改进方向。

4. 排版与图表赏析

p1 为标准 LaTeX article：居中大写标题（"SALES"系 "SAILS" 之误，唯一遗憾）、超长摘要把方法与全部关键数值（500 days、183158 m²、718 kg、1.14 rad、978 kg）加粗呈现。带目录、页眉 "Team 744 / Page x of 34"、脚注，公式编号连续 (1)–(33)，图表规范：Figure 1–10 + Table 1–4，图注自含结论（如 Figure 8 右图直接标注 65.38° 发射相位角）。附录 A 推导 Hohmann 方程，附录 B 放 13 页 Python 代码（含动画输出与 JSON 存档）。整体是"小论文+完整工程包"的气质。

5. 获奖密码：为什么能拿金牌

  1. 物理保真度最高：非理想 SRP 三系数模型 + 逐项推导（式 7–17），并向评委证明数据来源（文献 [9]），模型可信度上一个档次。
  2. 双目标优化框架干净：罚函数 + 权重的设计让"可行性"与"最优性"解耦，且对权重做了量纲解释。
  3. 收敛性与稳定性检验成体系：分区数扫描 + 初值重复 + 权重扫描，这正是评委眼中"数值结果可信"的黄金证据链。
  4. 超越题设的增值：最优发射相位角 1.14 rad、反向轨迹，展示模型是通用工具而非一次性拟合。
  5. 诚实披露失败：Jupiter 算例溢出、无法保证全局最优、需手动初值，弱点段写得具体。
  6. 排版信息密度高：摘要即全文缩影，表格即决策依据，评委无需翻代码即可复核。

6. 可借鉴清单

  1. 引入非理想帆系数 $b_1,b_2,b_3$ 成本低（三个常数），却显著提升物理档次。
  2. 把"到达条件"写成 $\max(\cdot,0)$ 罚项 + 权重目标，是处理多约束终端问题的万能套路。
  3. 对分段控制量做 1–30 段的收敛性扫描，一张表就能证明解稳定。
  4. 数值实验用固定单位制（如全部换 AU/天）避免浮点溢出——这是 744 用失败换来的教训。
  5. 在题设之外做"如果放开某约束会怎样"的扩展分析，是金牌论文的常见加分项。
  6. 目标函数权重本身也做灵敏度（Table 4），防止"最优解依赖人为权重"的质疑。
