Stability Research of Quadcopter UAV Under Unstable Wind（2020 题B 队伍380）

页数: 39 页 ｜ 对应题目: Quadcopter Stability in Wind（四旋翼无人机抗风稳定性）

1. 论文速览

同一道四旋翼抗风题，国防科技大学 380 队走了一条与"专业飞控"不同的路：先把真实风"分解"为基本风 + 阵风（gust）+ 渐变风（gradient）+ 随机风四分量叠加，再建立悬停动力学与水平面质点力模型，用仿弹簧的比例反馈机构模拟无人机纠偏，最后以风速变化因子 $\epsilon$ 扫描搜索临界风速。理论最大风速均值 5.3678 m/s、仿真均值 5.3487 m/s（摘要给出两数互相印证），例如 $\epsilon=0.5$ 时临界基本风 $V_b=2.65$ m/s、理论 $V_{\max}=(1+2\times0.5)\times2.65=5.30$ m/s，仿真峰值 5.2994 m/s。

2. 建模体系逐层拆解

第一层：风场分解模型（4.1 节）。 论文先论证 Von Karman 与 Dryden 模型"更适合高空风场"，而四旋翼飞行在超低空，故自建四分量自然风：基本风 $V_b=k$（式(1)）；阵风用余弦脉冲（式(2)，周期 $T_g=10$ s）；渐变风用分段线性函数（式(3)，周期 $T_r$ 相关）；随机风 $V_n = V_n^{\max} R(-1,1)\cos(\omega_n t)$，$\omega_n$ 在 $[0.5\pi, 2\pi]$ rad/s 内随机（式(4)）。合成风速 $V=V_b+V_g+V_r+V_n$（式(5)），并定义最大风速 $V_{\max}=V_b^{\max}+V_g^{\max}+V_r^{\max}+V_n^{\max}$（式(6)）。这一"拒绝套现成湍流模型 + 给出理由"的论证是全文的亮点：模型选择本身成了物理判断。

第二层：悬停动力学（4.2 节）。 选 X 型四旋翼结构并说明理由（相邻转子反转抵消反扭矩）；地面系/机体系经三次单轴旋转得姿态矩阵（式(10)–(13)），再转置得 $R_{e\to b}$（式(14)，利用旋转矩阵正交性 $R^TR=I$，式(9)）。总升力 $F_i\in[0,7]$ N（式(15)），风阻 $f=\frac{1}{2}C\rho S\sin\theta\, v^2$（式(7)、(18) 按轴分解），合成平动方程（式(19)–(21)）。

第三层：水平面简化模型（4.2.5 节）。 把无人机简化为质点：$F\cos\theta=G$（式(23)）、$F\sin\theta - f = ma$（式(24)），并给出最大水平拉力分量 $F_{\text{lift}}^{\max}=\sqrt{28^2-F_{\text{wind}}^2}$（式(26)）——直接把题目给的四转子 28 N 总推力上限转成约束。

第四层：仿弹簧反馈控制（4.3 节）。 先定性讨论风速/风向变化对应的调整策略（Fig.5、Fig.6 框图），再定量：设采样周期 0.2 s（模拟传感器 5 Hz 采样与执行延迟），若 $f(t-1)<2F_{\max}$ 则调整力 $F(t)=f(t-1)+f(t-1)\cdot x^*/x_{\max}$（式(27)），越界时切换为满舵饱和式(28)。附录代码显示实现为 $F_{p1}=-F_f(t-1)-\max(F_f)\,x/0.2$，即以"偏离 20 cm 时恰用满修正力"为刚度的比例反馈——像一根弹簧把无人机拉回目标点。

第五层：稳定性判据与参数（5.1 节）。 明确定义"稳定"＝60 s 内偏移不超过 20 cm（Fig.8 示意），并据无人机尺寸表（Table 1）算出顶面迎风面积 $S_1=0.0583$ m²、侧面 $S_2=0.6102$ m²（式(31)(32)）、$C=0.3$、$\rho=1.225$ kg/m³。

3. 数学方法与算法

纯数值仿真路线：以 0.2 s 步长的欧拉法在 MATLAB 中积分（附录给出完整 Main Code 与 Secondary Code，含固定随机种子 rand('seed',1) 保证可复现）。搜索算法为步长 0.01 m/s 的遍历：从 0 逐步增大 $V_b$ 直至 60 s 内偏移破 20 cm。引入风速变化因子 $\epsilon\in[0,1]$（$V_g^{\max}=V_r^{\max}=\epsilon V_b$，$V_n^{\max}=\epsilon V_b/2$），导出理论关系 $V_{\max}=(1+2\epsilon)V_b$（式(35)），随后做双重校验：三个代表值 $\epsilon=0.5,0.8,0.2$ 处理论与仿真对比（式(36)–(38)：5.30/5.2994、5.564/5.5375、5.474/5.4619 m/s，均得 $V_{\max}^{\max}\approx V^{Sim}$），再对 $\epsilon\in[0,1]$ 全程 100 步扫描（Fig.19、Fig.20 局部放大），取均值 5.3678 m/s（理论）与 5.3487 m/s（仿真）。"理论公式 + 全程仿真互相夹逼"是本文最扎实的自洽性检验。瑕疵：式(36)中理论最大风速与仿真峰值比的是不同含义的量（包络 vs 一次实现），且 5.5 节结论写 5.2795 m/s 与摘要 5.3678 m/s 不一致（疑为笔误）。

5. 获奖密码：为什么能拿金牌

  1. 先回答"为什么不用标准模型"。 明确论证 Dryden/Von Karman 适用于高空而非超低空，再自建四分量风——评委看到的是物理判断力而非模板套用。
  2. 自创"风速变化因子"参数化不确定风。 把"风怎么变"这个开放问题压缩为单参数 $\epsilon$，既得到闭式关系 $V_{\max}=(1+2\epsilon)V_b$，又把灵敏度分析变成一条曲线（Fig.19），一箭双雕。
  3. 理论—仿真双轨互验。 三个 $\epsilon$ 值逐一对照 + 全程扫描取均值（5.3678 vs 5.3487 m/s，相对偏差约 0.4%），自洽性检验做满了。
  4. 对题目约束逐条落实。 28 N 总推力上限（式(26)）、20 cm 偏移、60 s 时限、"风非定常"（采样 5 Hz + 0.2 s 响应延迟）全部转成模型中的显式约束或参数。
  5. 39 页的信息管理。 目录 + 连续公式号 + 附录代码，长而不乱，评委可快速定位任一结果。
  6. 诚实的优缺点评估。 6.2 节承认仅研究水平风、调整策略欠定量，并在 6.3 节给出正交分解、按位置切换策略等具体改进路径。

6. 可借鉴清单

  1. 遇到"真实环境不确定"类题目，可模仿"四分量分解 + 单一变化因子 $\epsilon$ 参数化"的手法，把开放的不确定性变成可扫描、可画曲线的维度。
  2. 必做"理论极值公式 vs 数值仿真峰值"的双重校验，两数几乎重合时是最有力的正确性证据（如本文式(36)–(38)）。
  3. 把执行机构的现实限制（推力上限、传感器采样率、响应延迟 0.2 s）显式写进模型，能显著提升真实感与评委信任度。
  4. 临界值搜索后务必做"越界对照实验"：本文 Fig.12/14 用 2.65 与 2.66 m/s 两幅图证明临界值卡得准，这一步常被参赛者省略。
  5. 长论文配目录与连续公式编号；附录放带固定随机种子的完整代码，承诺可复现。
  6. 自建简化反馈律时可类比物理原型（本文的"弹簧"类比），让评委一眼看懂控制逻辑的物理含义。
