同题异构对比观察

题 A：四支队伍给出四个相差三个数量级的答案，却都是金牌。 346 给出"纯动能偏转需 4.8 年（$3.8\times10^9$ km）、撞碎方案 15 小时（$1.3\times10^6$ km）"的双答案；395 给出 58–139 天；425 给出 0.1–0.7 年；460 给出 14 年（化学火箭）/0.67 年（Hall 推进器）。数字的巨大分歧恰恰暴露了题目开放性——"让小行星错过地球"的判据本身（角动量不等式、距地心 $10^7$ m、时间提前量 $n\Delta T > R_z/v$、擦地切线条件）各自不同，而评委显然奖励的是"判据 → 方程 → 数值"链条的自洽与物理洞察，不是某个"正确数字"。对参赛者的启示是：把成功判据明确写出并论证其合理性，比追求与他人一致的答案重要得多。

题 A：撞击几何的三种互补结论。 425 用两组扫掠仿真证明最优撞击是"近日点、沿小行星速度方向"（改变周期最有效）；460 用 $p/P\sim10^{-6}$ 的标度分析证明"正面顶停不可能"、应垂直侧推并取 $\alpha = 0$；395 同样选择垂直于原速度方向撞击；346 则把撞击点位置折叠进角动量判据的 $r^2$ 因子（"越早越省动量"）。四者表面上不同，实际上自洽：425 改变的是轨道周期（切向冲量），460/395 追求的是单位动量的横向位移最大化（法向冲量），346 的判据则说明何时撞击比往哪儿撞更重要——同题异构在此体现为"优化目标函数不同导致最优策略表述不同"。

题 B：Magnus 力建模的三级台阶。 三支题 B 队伍最终都收敛到同一表达式 $\vec F_m = \frac{8}{3}\pi\rho r^3\,\vec\omega\times\vec v$（358 式 (7)、471 式 (10)、480 式 (1)），但对自转的处理构成递进：358 先解出 $\omega = \omega_0e^{-kt}$ 再用数量级论证"飞行 1 秒内衰减不足 0.1%"，正当取常值；471 先假设光滑球取常值、第 7 节用 Stokes 黏性力矩 + 空心球转动惯量 $I=\frac{2}{3}ma^2$ 正式修正为 $\omega' = \omega_0e^{-9\pi\eta a t/m}$，形成"假设-回收"叙事；480 则一步到位把 $e^{-\mu t}$ 写进运动方程 (7)（但 $\mu=0.1$ 为硬编码，按其参数推算仅约 0.009，处理偏粗）。阻力系数的处理同样分层：358 取常数 $C_a=0.4$，471 用 Asai 实验曲线插值让 $C_d$ 从 0.5 降到 0.06（捕捉阻力危机，唯一一家），480 取常数 $c=0.5$。这组对照说明：同一物理效应的"常数近似 / 量级论证近似 / 显式建模 / 事后修正"四种深度都可以拿金牌，差别在于你是否把所选深度讲出自洽理由。

题 B：守门员建模的三种范式。 358 走"解剖学 + 几何可达域 + 概率"路线：肩高、臂长引艺用解剖学文献，直立与扑救两模式分别给可达域，再以重叠次数加权二维正态分布做蒙特卡洛风险热图，最后求绝对死角；471 走"时间公式"路线：把扑救写成两段式时间函数 (19)（低于重心先降重心再平移），以 $t_{simulation}\le t_s$ 直接作约束筛出 1108 组可行策略；480 走"极值面积"路线：蹬地模型 (8)–(10) → 斜抛位移 (14)(15) → 面积积分对起跳角求极值得 $\alpha = 57.52°$、$s_{max}=13.34$ m²，并取"守门员全知全能"的最坏情形。三者分别把"对手"建成了概率场、时间约束与几何包络——这为"含人的对抗系统"提供了三种可复用的建模范式。

题 B：最优化呈现与结论反差。 在"最优策略"的最终表达上，358 给出必进死角的角度区间（$\theta\in[76.95°,78.95°]$ 等），471 给出精度最高的单点解（距上角中心 0.0118 m）加 1108 组策略分布，480 则反转题目"射上角"的暗示、用 ±2 单位扰动重采样与世界杯 16 年统计主张射下角（$v_0=21.245$ m/s）。值得注意的共性是：三队都不满足于回答"哪些初条件能进球"，而是把第二问升级为决策建议（风险最小/时间最紧/鲁棒性最强），这正是 UPC 评委在"best chance"这一措辞里期待的东西。另外两处模板差异也值得留意：395 与 471 采用 MCM 式 Summary Sheet + 目录 + 分节评述的"美赛风"，346/425/460/358 采用 UPC 摘要页式的"期刊风"，480 为 Word 排版——模板不影响获奖，但 471/480 的案例研究与数据可视化说明，"把结果讲成决策故事"的能力是跨模板的通用加分项。
