## 2. 核心模型库逐一解读

### 2.1 Lagrange 多体动力学（2010B 投石机）

**适用场景**：约束连杆系统（摆、吊索、多连杆），坐标受几何约束、只有保守力做功时最自然。**方程**：二自由度（梁角 $\varphi_1$、吊索角 $\varphi_2$），动能含耦合项 $\cos(\varphi_1-\varphi_2)$，得两个耦合非线性二阶 ODE，无解析解转数值。

**金牌处理**（Team 210，圣路易斯大学，单人队）：全部参数符号化保留（$I_{zz}$ 最后代入，换任意梁截面/材料零成本）；自设题面留白的弹丸质量 100 kg、支点高 1.5 m；一阶 Taylor 自写 C++ 积分 + 0.01 m 网格三维穷举，得 $r_1=0.51$、$r_2=0.91$、$r_3=0.58$ m、$v_3=17.48$ m/s，效率 $\eta\approx31\%$；最优解紧贴约束边界（$r_2+r_3=1.49\approx h_0$、"抛掷端恰好擦地"；$r_1$ 紧贴"配重够到 2 m"下限）——**最优解贴边 = 约束主导**，本身是重要发现。**常见错误**：把"配重举高 2 m"当"下落 2 m"（实际下降量由 $r_1,h_0$ 决定，金牌构型仅 ~1 m，能量预算差一倍）；优化不设物理可行域（搜出穿地解）；把单一构型的"吊索:长臂≈2:3"法则外推成普适定律；能量守恒自检缺失（一行代码即可抓积分器 bug）。

### 2.2 恢复系数碰撞与事件驱动分段仿真（2011B、2012B、2015B）

**适用场景**：球类与边界（地板/篮板/篮筐/树）的反复碰撞。**方程**：法向恢复系数 $e$（2015B 用 Penner 的 $e(v_\perp)$，随撞速变化），切向摩擦反弹 $v'_\parallel=\tfrac57v_\parallel-\tfrac27R\omega_r$（Daish），弹跳总长为公比 $e$ 的几何级数，滚动 $L_r=v'^2_\parallel/2\mu g$。

**金牌处理**：2011B-379（RIT）是标准模板——MATLAB ode45（RelTol 1e-5）事件驱动分段仿真，参数全部官方化（FIBA 规则表），6 维解空间用"纯后旋"假设降维，$(v_0,\varphi,\theta)$ 空间产出灰度命中图，并与 Silverberg 文献交叉验证。2012B-414（上海交大，首支中国大陆金牌队）的巧思在耦合：球尺寸变大 → 转动惯量变 → 同样击球下转速按角动量守恒自动降低 → 阻力与 Magnus 同时改变——把"观赏性"操作化为人眼追踪基准（30°/s → 11.88 m/s），转播几何入模，结论 44 mm。2015B-108 把碰撞矩阵化：杆-球斜碰撞写成 10 元线性方程组 $\mathbf b=P\mathbf v$（法向/切向动量守恒 + 角动量守恒 $mRV+I\omega=0$），附录逐行标注物理含义。**常见错误**：恢复系数取常数（实际随撞速变化）；backspin 过大时 $v'_\parallel<0$ 球会回滚的情形漏掉；"落地即停"忽略弹跳与滚动，落点判据失真。

### 2.3 约束轨道与过载设计（2019B 过山车）

**方程两派**：190 队（Nuova-Prime）写五段轨道（斜坡/三连半圆/上爬坡/双螺旋/下坡+圆弧）的牛顿运动 ODE + 平方空气阻力 + 分段摩擦系数，递归欧拉法（$\Delta t=10^{-4}$ s）+ 能量总账 $Mgh$ 校验；389 队用 9 分段动能定理递推（半解析），clothoid 环 + 大半径回转做轨道选型，风阻 $F_w=\tfrac12\rho A_DC_Dv^2$。

**关键套路——把"安全/刺激"指标化**：190 队的 $S=4G_x+5G_y+3G_z+0.05v+0.1H$，权重与阈值均有 NASA 文献与独立标定；389 队用"4.1 g + 0.01 s"判据。**验证范本**：389 用领域仿真器 NoLimits 2 独立复核（拟合度 94.26%、平均误差 2.1 m/s）——"理论 + 领域仿真器"双轨互验是设计类题的高性价比动作。**陷阱**：竖直环顶的最小速度条件（$v^2\ge gr$）与过载峰值位置；摩擦系数分段不连续处能量跳变。

### 2.4 非线性弹性与人-结构耦合（2023B 蹦床）

**共同起点**：弹簧几何伸长 → 竖直投影 $F_v(x)$。**三条技术路线**：102 队走"线性化 + 修正"——先画 $F_v(x)$ 曲线标定线性区（$x<0.5$ m、$k=8000$ N/m），修正阶段回到二次律 $F_v\approx\frac{NsK_s}{2R}x^2$，用对比图证明简化误差可忽略（最稳健）；138 队工程化最深——单簧刚度 $k=Gd^4/(8nD^3)\approx712940$ N/m、弹簧数按国际体联标准折算 135 根、网面微元 PDE 论证"V 形网"、等效网面质量 $m_k\approx2$ kg + 完全非弹性碰撞 $v_0=-\frac{m_0}{m_0+m_k}\sqrt{2gh}$；471 队最解析——不把 $\frac13M$ 当经验值，而从网面速度线性分布 $v(r)=v_0(1-r/R)$ 面积分严格推出，且唯一考虑分段刚度（预紧段 96 kN/m / 工作段 2.7 kN/m），用周期平均能量收支 $\Delta E(h_{max})$ 与 DOP853 事件驱动仿真互证（偏差 <3%）。

**相位同步（本质是二维时延优化）三解法**：102 遍历初始条件；138 最完整（12 s 窗口粗扫 → 45° 坐标旋转精扫，并论证窗口完备性：三人周期最小公倍数 < 12 s）；471 最聪明——把物理洞察（"前一人停在最低点时后一人触网，能量全部存入弹簧"）直接变成确定性策略再枚举 6 种落地顺序。三队一致结论：**最轻的孩子飞得最高**；数值差异（1.28–3.67 m）源于保守假设不同，138 用市售护网 1.83 m 交叉验证、471 用能量审计（总增 214 J vs 肌肉注入 689 J）诚实承认可能高估。**陷阱**：人-网碰撞的恢复系数选择（完全非弹性 vs 接触共享 ODE）；"double bounce"能量传递机制讲不清就推广到三人。

### 2.5 姿态与旋转稳定性（2023A 部分，可迁移到 2020B 四旋翼）

**适用场景**：自由下落体的姿态失稳。**三种定量路线**：355（同济）把判据归并为单位质量气动力 $k=f/m$，用 Baumgartner 失控/恢复两个实测状态点标定阈值（$k_1=2.82$、$k_2=12.36$ N/kg）并原创耐受积分 $S=\int k\,dt$，回代复现失控时长（56.1 s vs 实际 ~52 s）——"单事件标定"范式；447（国防科大）从力矩平衡推出旋转-平动耦合系数"每损失 1 m/s 速度角速度增 2.2 rad/s"，配套 3.5G/6 s 触发的稳定伞工程出口；244 则完全忽略旋转并在局限中声明。2018A-258 的刚性球面帆微扰动力学（Newton + Euler 方程，平顶光束下解析积分 + 初扰动—振幅标度实验）与 2020B-335 的 Newton-Euler 六自由度同属此库的"全姿态"档。**陷阱**：跨声速翻滚既增大 $C_dA$ 又威胁生存，迎风面积随姿态切换不能漏；旋转判据的阈值缺乏实验支撑时要像 355 一样坦承。

## 3. 跨题目的建模套路总结

1. **自由度选择先于一切**：先声明广义坐标与约束（2010B 的 2 DOF、2023B 的竖直一维 + 碰撞），再选工具——保守系统用 Lagrange，含摩擦/驱动用牛顿递推或动能定理，姿态用欧拉方程。自由度多一个，扫描成本指数上涨（2011B 用"纯后旋"降维 6→3 维是经典处置）。
2. **事件函数是刚体题的粘合剂**：释放（投石机 $\varphi_1=\pi$）、碰撞（触地/触网/碰篮板）、切换（开伞、马赫）全部以事件驱动拼接，避免定步长过冲；释放瞬间的速度取约束端点速度、约束力即告消失。
3. **等效参数化 + 双向校准**：等效质量（$\frac13M$）、等效刚度（$S/V$、$C_dA$）把复杂结构压进低维模型，再用实测/商品参数双向校准（138 的视频逐帧 + 护网高度）——"标定—工程—解析"三种深度都可夺金，但所选深度必须被检验（471 的能量审计、210 的能量守恒漂移 <0.1%）。
4. **目标函数与可行域分开声明**：优化类题（投石机、三分球、蹦床时延）都先写清目标代理量（释放动能/命中概率/最大高度）与物理可行域（不穿地、FIBA 尺寸、蹬伸力 ≤ 体重），并检查最优解是否贴边。
5. **含人的对抗系统三种建模范式**（2022B 守门员的遗产，2023B 同样适用）：概率场（可达域 + 蒙特卡洛热图）、时间约束（扑救时间公式）、几何包络（蹬地斜抛极值面积）。

## 4. 备赛建议

**最小知识清单**：Lagrange 方程的现场推导（含耦合动能项）；转动惯量清单（细杆 $\frac13mL^2$、实心球 $\frac25mR^2$、空心球 $\frac23ma^2$）；恢复系数正/切向反弹公式与弹跳几何级数；约束轨道最小速度与过载 $G=v^2/(rg)+g$；弹簧串并联与几何投影刚度；角动量守恒做转速耦合；事件驱动数值框架（ode45 Events / solve_ivp events）与能量守恒自检。

**推荐练习题年份**：2010B（Lagrange + 符号化推导的祖师级范本）、2023B（三条深度路线 + 相位同步三解法，对照学习价值最高）、2019B（指标化 + 领域仿真器验证）、2011B 与 2015B（碰撞矩阵 + 可行域/裕度）。训练目标：拿到机构题先画"自由度—约束—事件"三栏表，再动手积分。
