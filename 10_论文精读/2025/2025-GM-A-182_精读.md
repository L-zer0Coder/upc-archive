### 1.3 §4 Pickup Selection（第 6–13 页）——选型论证的教科书

**它写了什么**：三种拾音器逐一过物理原理：
- **磁拾音**：法拉第定律 ε=−N dΦ_B/dt，输出∝磁通变化率，故为**速度敏感**。对位移波函数（式 2）求时间导数得式 (1)，每个谐波多乘一个因子 n·√ν·π/L——高次谐波被人为抬高（衰减从 1/n² 变 1/n），"electric instruments using magnetic pickups a different, often sharper tone"。另需铁磁性琴弦、怕工频电磁 hum。
- **压电**：本构方程 D=dT+ε₀E、S=sT+dᵀE，位移敏感；但输出阻抗高（C=ε_r ε₀ A/d 小 → Z=1/(2πfC) 大，需前放缓冲），且须钻入琴码——sasando 每弦琴码位置不同，需每弦独立系统，侵入性强。
- **光学**：H21B1 光断续器（IR LED+光电三极管），静止时遮半束光；Hanson (1987) 实验证实输出与位移**负线性**——位移敏感、非接触、抗电磁、琴弦材质不受限。
- §4.5 对比表按"保真/安装/抗扰"收束，选光学。
**为什么这样写**：每个候选都被**物理机理**否决或通过，而不是"网上说不好"。尤其磁拾音的否决理由是作者自己推的式 (1)——选型论证回到了第一性原理。
**你要学什么**：三类换能器的"敏感量"分析（位移 vs 速度）可以原样迁移到任何传感类题目；"velocity-sensitive 改变谐波权重 1/n²→1/n"这个论证是全文最漂亮的一步物理。

### 1.4 §5 Pickup Location（第 13–18 页）——波动方程的完整现场推导

**它写了什么**：从弦微元受力图（Fig 11）出发：F_x ∂²y/∂x² dx = ∂²y/∂t² ρA dx，得波动方程 ∂²y/∂t² = ν ∂²y/∂x²（式 3，ν=T/μ）。分离变量 y=F(x)G(t)（式 4），对 k<0/k=0/k>0 三情形逐一排查（后两者只给平凡解 F≡0，故 k 必为负），得 F(x)=C₂sin(nπx/L)（式 8–10）、G(t)=A cos(√ν nπ t/L)+B sin(...)（式 13），叠加成通解（式 15）；由初速为零定 Bₙ=0，得终解（式 17）。拾音器在 P 处拾得 n 次谐波幅度 Aₙ(P)=Aₙ sin(nπP/L)（式 18）；令 P=L/N，则 n=N 时幅度为零——**波节**。要保留尽可能多阶谐波，需 N→∞ 即 P→0：**拾音器应尽量贴近琴码**（x=0 端）。另附工程理由：拾取幅度小 → 后级 headroom 大、不易削波。
**为什么这样写**：作者不引用"教科书结果 sin(nπx/L)"，而是从受力微元**八步全推**（含三情形讨论）。推完后立刻把式 (19) 翻译成工程语言（"brighter, clearer tone"、"greater headroom"）——数学结论必须落到设计参数才有用。
**你要学什么**：**"传感器放哪"类问题的标准解法**：写出系统的模态形状 → 求测点对各模态的灵敏度 sin(nπP/L) → 让测点避开一切波节。适用于弦、管、梁、膜任何驻波系统。

### 1.5 §6 Band-pass Filter（第 18–23 页）

**它写了什么**：biquad 传递函数 H(z)=(b₀+b₁z⁻¹+b₂z⁻²)/(a₀+a₁z⁻¹+a₂z⁻²)（式 20）；采用 RBJ Audio EQ Cookbook 的恒定 0 dB 峰值增益带通系数（式 21–22）；Direct Form I 差分方程（式 23）；多滤波器**并联求和**（式 24）。6.1 叶共鸣器：f₀=√(98×1047)=320.32 Hz、BW=949 Hz、Q=f₀/BW=0.3375（低 Q ↔ 宽带共鸣，物理直觉自洽）；Fs=48 kHz（AES 标准）；算得 ω₀=0.04193 rad、α=0.0621，归一化系数（式 25）b=[0.059,0,−0.059]、a=[1.0,−1.9,0.88]；用高斯白噪声激励 + Welch PSD 验证带外抑制（Fig 12，附录 MATLAB 代码）。6.2 竹筒：闭管驻波 λₙ=2ℓ/n、fₙ=v/λₙ（式 26）给出 245/490/735/980/1225 Hz，前四阶落在叶共鸣带内→加四支高 Q biquad；Q=1/tanδ=1/0.053=19±2（竹材内摩擦取自 Liu et al. 2012 动态热机械分析，含水率 8.25%、25 °C）；**不确定度经 δα=α·δQ/Q 传递到每个系数**（如 245 Hz 节 a₁=−1.9972±2×10⁻⁴）。
**为什么这样写**：滤波器设计的每一步都有出处——中心频率用几何平均（对数刻度对称）、Q 由带宽定义、系数用 RBJ 闭式、验证用白噪声 PSD。竹筒 Q 不是拍脑袋（很多队伍会直接设 Q=10），而是从**材料内摩擦数据**推出来并带误差棒。
**你要学什么**：①"材料学数据 → Q=1/tanδ → 滤波器系数 ± 区间"这条链可以直接抄；②白噪声+Welch 是验证数字滤波器最便宜的黑箱方法；③把不确定度传递到**最终交付物**（系数），本批 17 篇中独一份。

**它写了什么**：A/B/AB 三类功放对比，选效率 50–70% 的 Class AB；增益定义 A_v=V_out/V_in 等、η=P_out/P_in。§8.1 全链路框图（Fig 15）：光拾音×每弦 → 前放 → ADC → biquad 组 → DAC → Class AB → 动圈扬声器。§8.3 自评三条弱点：多弦成本（violin 型 32–36 弦）、有源供电、数字链路时延与 ADC 分辨率折衷。

**核心图复现——RBJ 带通频响 + 竹筒四谐振（Fig 12 与 6.2 节表的 Python 等价）**：

```python
import numpy as np, matplotlib.pyplot as plt

Fs, fL, fH = 48000.0, 98.0, 1047.0          # 论文 6.1 节常量
f0 = np.sqrt(fL*fH)                          # 中心频率=几何平均 → 320.32 Hz
Q  = f0/(fH-fL)                              # Q=f0/BW → 0.3375
w0 = 2*np.pi*f0/Fs; a_RBJ = np.sin(w0)/(2*Q) # 式(22)
b = np.array([a_RBJ, 0, -a_RBJ])/ (1+a_RBJ)  # 式(21)并按 a0 归一化 → 式(25)
a = np.array([1, -2*np.cos(w0)/(1+a_RBJ), (1-a_RBJ)/(1+a_RBJ)])

def H(f):                                    # 频响 H(z), z=exp(jw)
    z = np.exp(2j*np.pi*f/Fs); z1, z2 = 1/z, 1/z**2
    return (b[0]+b[1]*z1+b[2]*z2)/(a[0]+a[1]*z1+a[2]*z2)

f = np.logspace(1.3, 4, 2000)
mag = 20*np.log10(np.abs(H(f)))
# 审计: |H(fL)|=|H(fH)|=-3.01 dB, |H(f0)|=0 dB → 恒 0 dB 峰值增益带通成立 ✓
fig, ax = plt.subplots(figsize=(7, 4.2))
ax.semilogx(f, mag, lw=1.5)
for fc, ls in [(fL,'--'),(fH,'--')]:
    ax.axvline(fc, color='k', ls=ls, lw=0.8)
for n in range(1, 5):                        # 竹筒四谐振(式26): f=n·343/1.4
    ax.axvline(n*343/1.4, color='r', ls=':', lw=0.8)
ax.set(xlim=(40, 1e4), ylim=(-60, 6), xlabel='Frequency (Hz)',
       ylabel='|H(f)| (dB)',
       title=f'RBJ BPF: f0={f0:.1f} Hz, Q={Q:.3f} → b0={b[0]:.3f}, '
             f'a1={a[1]:.3f}, a2={a[2]:.3f}\n'
             f'-3 dB at {fL}/{fH} Hz (dashed); bamboo harmonics 245/490/735/980 Hz (dotted)')
ax.grid(alpha=.3, which='both'); plt.tight_layout(); plt.show()
```

三个可偷的绘图决策：**① 红色虚线标出竹筒四谐振与叶通带边界的相对位置**（这张"通带+谐振叠加图"论文其实没画——四支竹筒 biquad 的频响未单独验证，是本篇可挑剔处）；**② 图题直接写系数与 −3 dB 验证结论**；**③ 白噪声 PSD 验证（灰输入 vs 红理论输出）是滤波器论文的标配图**。

## 3. 公式逐条精讲

### 3.1 拾音器敏感量与谐波权重（式 1 vs 式 2）

$$\frac{\partial y}{\partial t}=-\sum_{n=1}^{\infty}\frac{\sqrt{\nu}\,n\pi A_n}{L}\sin\Big(\frac{n\pi x}{L}\Big)\sin\Big(\frac{\sqrt{\nu}\,n\pi t}{L}\Big)\tag{1}$$

- **怎么想到**：判断拾音器"改变音色"与否，只需比较它对每个谐波的增益权重。位移敏感→权重 Aₙ（式 2，拨弦傅里叶系数 Aₙ∝1/n²）；速度敏感→对时间求导，权重多乘 n·√νπ/L（式 1），高次谐波相对抬高。
- **数值感**：n=10 的谐波，位移拾取权重 1/100，速度拾取 1/10——十倍增强，这就是电吉他"尖亮"的数学来源。
- **适用边界**：理想拾音点假设；实际磁拾音还有非对称磁化非线性（Mustonen 2014），此处一阶近似够用。

### 3.2 波动方程的微元推导（式 3 及其前导）

$$F_x\frac{\partial^2 y}{\partial x^2}dx=\frac{\partial^2 y}{\partial t^2}\rho A\,dx\;\Rightarrow\;\frac{\partial^2 y}{\partial t^2}=\nu\frac{\partial^2 y}{\partial x^2},\quad \nu=\sqrt{\frac{T}{\mu}}\tag{3}$$

- **怎么想到**：微元左右张力的 y 分量差 F_y2−F_y1=F_x(tanθ₂−tanθ₁)=F_x ∂(∂y/∂x)，牛顿第二定律除以 dm=ρA dx。四步：几何（斜率）→ 力差 → 除质量 → 识别常数=T/μ。
- **注意论文的一个记号瑕疵**：正文写 ν=√(T/μ) 附近排版为 "ν = T/μ"（开方号疑似丢失，以 PDF 原式为准），但其后所有频率公式均按 √ν 使用，实际计算不受影响。
- **适用边界**：小挠度、恒张力、无阻尼——§2.3 的六条假设正是给这三条铺路。

### 3.3 分离变量与三情形排查（式 4–13）

**完整链**：设 y=F(x)G(t)（式 4）→ 两边除以 νFG 得 G″/(νG)=F″/F=k（式 5–6）→ k=0 与 k>0 代入边界条件 F(0)=F(L)=0（式 7）只得零解（平凡解必须排除，这一步很多论文跳过）→ k=−a² 时 F=C₁cos ax+C₂sin ax（式 8），F(0)=0 杀掉 C₁，F(L)=0 要求 sin(aL)=0 → a=nπ/L（式 9）→ 时间方程因式分解 (d/dt+iω)(d/dt−iω)=0 解得 G=A cos(ωₙt)+B sin(ωₙt)（式 13），ωₙ=√ν nπ/L。
- **你要学什么**：**三情形排查不是数学洁癖，是证明"频谱必离散"的必要步骤**——只有 k<0 才有非平凡解，离散本征值 nπ/L 从这里蹦出来。48 小时论文里能完整写这一段的队伍极少。

### 3.4 波节与拾音位置（式 18–19）

$$A_n(P)=A_n\sin\frac{n\pi P}{L},\qquad A_n\Big(\frac{L}{N}\Big)=A_n\sin\frac{n\pi}{N}$$

- **怎么想到**：拾音器是"单点采样器"，它对 n 阶模态的灵敏度就是模态形状在该点的值。P=L/N 时 sin(nπ/N) 在 n=N 及其整数倍处为零——**第 N 阶谐波整个消失**。
- **推导链结论**：要同时保留 1..N 阶，须 N 尽量大 → P=L/N 尽量小 → **贴码放置**。
- **数值感**：P=L/20 时第 20、40…阶谐波消失；P→0 时所有 sin(nπP/L)≈nπP/L 同比例缩小——谐波**结构**保留、幅度整体变小（这正是 headroom 论述的来源）。
- **适用边界**：只保留谐波"结构"不等于音色完全一致——拾音点也影响与拨弦点 p 的卷积（Fig 9 已涉及 p=L/6 的情形），论文未展开 P 与 p 的交互，属可深挖处。

### 3.5 RBJ biquad 带通（式 20–23）

$$H(z)=\frac{b_0+b_1z^{-1}+b_2z^{-2}}{a_0+a_1z^{-1}+a_2z^{-2}},\quad b_0=\alpha,\ b_1=0,\ b_2=-\alpha,\ a_0=1+\alpha,\ a_1=-2\cos\omega_0,\ a_2=1-\alpha$$
$$\omega_0=\frac{2\pi f_0}{F_s},\qquad \alpha=\frac{\sin\omega_0}{2Q}$$

- **怎么想到**：要用数字滤波器模仿声学共鸣器，最自然的选择是"二阶谐振子等价物"——biquad。RBJ Cookbook 的恒 0 dB 峰值增益变体保证通带中心增益恰为 1、f_L/f_H 处恰 −3 dB（审计复算：|H(98)|=|H(1047)|=−3.01 dB、|H(320.3)|=0 dB，精确成立 ✓）。
- **数值核对（审计）**：f₀=320.3217 ✓、Q=0.3375 ✓、ω₀=0.04193 ✓、α=0.06209 ✓；归一化 b₀=0.0585（论文 0.059 ✓）、a₁=−1.8814（论文写 −1.9，两位有效数字舍入）、a₂=0.8831（论文 0.88 ✓）——**全部一致**，仅论文中间步骤把 a₁=−1.9982 舍成 −2.0 又用未舍入值归一化，前后口径略粗 ⚠（不影响最终系数）。
- **适用边界**：ω₀≪1 时 α≈ω₀/2Q；并联多支滤波器（式 24）假设各共振独立无干涉，对高 Q 竹筒谐振成立（间隔 245 Hz ≫ 各自带宽 245/19≈13 Hz）。

### 3.6 闭管驻波与材料 Q 值（式 26 与 Q=1/tanδ）

$$\lambda_n=\frac{2\ell}{n},\qquad f_n=\frac{v}{\lambda_n};\qquad Q=\frac{1}{\tan\delta}=\frac{1}{0.053}=19\pm2$$

- **怎么想到**：两端封闭→两端皆波节→半波长整数倍拟合管长；fₙ=n·v/(2ℓ)=n×245 Hz（v=343、ℓ=0.7）。Q=1/tanδ 是黏弹性材料共振峰锐度与内摩擦损耗的标准倒数关系。
- **审计**：245/490/735/980/1225 Hz 逐项复算 ✓；Q=18.87、δQ=Q·δ(tanδ)/tanδ=1.78≈2 ✓（误差传播公式正确）。
- **适用边界**：竹筒实际是"闭管+薄壁竹材振动"的耦合体，纯空气柱模型忽略壁面振动模态；8 cm 直径未用于修正（端部效应 ~0.6r ≈ 2.4 cm 对 70 cm 管长约 3% 频移，论文未讨论 ⚠）。结论文本把 980 Hz 误写为 908 Hz（第 26 页 Conclusion），以正文表格为准 ⚠。

## 4. 建模决策链

| 决策 | 作者的选择 | 被放弃的替代 | 为什么 |
|---|---|---|---|
| 乐器形制 | gong 型、9–11 弦 | violin 型 32–36 弦 | 最简形制先把方法走通，弦数留在弱点自评 |
| 拾音器 | 光学（H21B1 光断续器） | 磁（改谐波权重+需铁弦）、压电（高阻+侵入琴码） | 位移敏感保音色、非接触、抗扰 |

| 共鸣复现 | 数字 biquad 并联组 | 模拟电路滤波器 | 参数可调、免元件容差、多共振零成本 |
| 叶通带 Q | 0.34（几何平均中心频率） | 高 Q 窄带 | 叶共鸣是宽带放大（98–1047 Hz），低 Q 物理自洽 |
| 竹筒 Q | 1/tanδ=19±2 | 拍脑袋常数 | 从材料 DMA 数据推出且带误差传递 |
| 采样率 | 48 kHz（AES 标准） | 44.1 kHz | 音频制作推荐值，防混叠、软件兼容 |
| 功放 | Class AB（η=50–70%） | A 类（效率低）、B 类（交越失真） | 效率与线性的折衷 |

**总规律**：每个决策都对应一条"物理机理或文献数据"，没有一条是"我们觉得"。加上把 tanδ 的 ±0.005 一路传到系数的 ±10⁻⁴，构成全文的可信度骨架。
