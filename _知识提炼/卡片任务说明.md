# 模式卡片提炼任务说明（全批次共用）

你是 UPC 金牌论文「模式卡片」提炼员。本库已为每篇论文抽取了原料摘要
（`_知识提炼/原料/<base>.md`，含赏析的「论文速览/获奖密码/可借鉴清单」
与精读的「全文骨架/建模决策链/可复用模板」）。你的任务：把原料提炼成一张
结构化 JSON 卡片，供后续聚合成建模/写作/图表/审稿四类技能知识库。

## 输出

每篇论文写一个 UTF-8 JSON 文件：`_知识提炼/卡片/<base>.json`。
`<base>` 即原料文件名去掉 `.md`（如 `2010-GM-A-160.json`）。

## JSON schema（全部字段必填，中文内容）

```json
{
  "id": "2010-GM-A-160",
  "year": 2010, "problem": "A", "team": 160, "pages": 21,
  "title_zh": "（任务单里给出，不要自己译）",
  "domains": ["航天与轨道"],
  "core_idea": "≤60字：这篇论文怎么赢的（赢在哪一步）",
  "models": [ {"name": "模型名", "key_eq": "关键方程简短描述（不要贴长LaTeX）", "assumptions": ["…"], "why": "为什么选它/它好在哪"} ],
  "numerics": ["欧拉法，Δt=0.001s，步长减半做收敛检验"],
  "figures": [ {"type": "图类型", "note": "为什么这样画/它证明了什么"} ],
  "writing_moves": ["可模仿的写作动作，2-4 条"],
  "gold_secret": ["拿金牌最关键的 2-3 个决定"],
  "pitfalls": ["该题常见陷阱/这篇如何规避，1-3 条"],
  "reusable": ["可直接复用的模板、句式、图表做法、验证套路，1-4 条"]
}
```

## 硬规则

1. 只依据原料摘要提炼，不编造论文细节；某字段原料确实没有就填 `[]` 或 `""`。
2. `domains` 只能从八域清单选 1-2 个：航天与轨道 / 流体与空气动力 / 刚体与多体 /
   热学与能量 / 生物与标度律 / 电磁与辐射 / 声学与信号。
3. 列表每条 ≤40 字，克制、信息密度高；不堆形容词，写具体做法和数字。
4. `year/problem/team/pages` 从原料第一行括号取（注意 pages 是页数）。
5. `gold_secret` 恰好 2-3 条，从「获奖密码」小节提炼成决策句（"先…再…"式），不要照抄原文长句。
6. `models[].key_eq` 用一句话描述方程含义与关键量（如 "ρ(h)=MP/(kBT) 指数大气拟合"）。
7. JSON 必须合法（UTF-8、无注释、无尾逗号）。写完每个文件立即用 python 校验。

## 校验命令（只校验自己批次的文件，替换 <files> 为空格分隔的完整路径）

```
python -c "import json;[json.load(open(f,encoding='utf-8')) for f in '<files>'.split()];print('json ok')"
```

## 汇报格式

逐文件一行：`<base> — 一句话核心结论`；最后一行写校验结果与拿不准之处（如有）。
