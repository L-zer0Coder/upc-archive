# 2015-GM-B-108（2015 题B · 队伍 108 · 25 页）

## 来自赏析

### 论文速览

论文将球的运动划分为 Free-flight Stage 与 Bouncing Stage 两段，核心物理判断是：**Magnus 力是球能绕行圆柱的根本原因**——backspin 提供升力延长飞行，sidespin 提供侧向力把球"拉回"果岭。杆-球碰撞用斜碰撞的动量/角动量守恒写成 10 元线性方程组的矩阵形式（式 6、式 21-22），自由飞行段用带二次阻力（式 7）与 Magnus 力（式 8）的三维 ODE（式 9）数值积分，落地段用 Penner 的恢复系数经验式（式 12）与 Daish 的反弹公式（式 11）解析处理，最终在 $(\psi,\gamma)$ 参数空间扫出可行域（Figure 7-8），并定义"系统裕度"$M$（式 20）量化容差，给出可操作建议：loft 22.5°、drift 约 17°、偏离树 44° 方向、速度约 60 m/s。

### 获奖密码

1. **抓住题眼物理**：绕树必须靠侧向持续力，sidespin-Magnus 是唯一合理机制，全文围绕它组织，结论有明确物理归因而非"数值试出来了"。
2. **两阶段拆分 + 全链条交互建模**：杆-球、球-空气、球-地面三种相互作用各有专属模型与系数来源（Cochran & Stobbs、Penner、Daish），题目的"ball/club interaction"被正面回答。
3. **可行域语言**：不满足于一条成功轨迹，而是扫出 $(\psi,\gamma)$ 平面的可行区域并指出其中心对称性，直接回应"描述相互作用"的开放性要求。
4. **裕度 $M$ 的原创量化**：承认人手存在误差，把鲁棒性变成可优化的目标函数，再反推"最稳打法"——从解题升级为设计建议。
5. **经验系数文献化**：恢复系数随撞击速度变化的拟合式（式 12）、µ=1.0 等全部注明 Penner 等出处，避免"拍系数"。
6. **扩展模型展示余量**：侧风分析说明团队有余力处理真实条件，且事件驱动代码框架换参数即可复用。

### 可借鉴清单

1. 运动过程明显的题目先做"阶段划分"，每阶段选最合适的数学工具（碰撞=代数方程，飞行=ODE，弹跳=级数）。
2. 多守恒律联立的碰撞问题写成矩阵形式 $\mathbf b=P\mathbf v$ 并逐行注明物理含义，可解性一目了然。
3. 数值积分用事件函数（EventLocator/ode45 Events）捕捉碰撞/落地面，避免定步长积分的过冲误差。
4. 对"怎么打才行"类问题，交付可行域图 + 容差量化指标（如裕度 RMS），比单点答案更有用。
5. 空气动力系数（$C_D$、Magnus 系数）务必引文献或实验数据，并讨论表面条件（凹坑）的影响。
6. 收尾给"教练式建议"（具体角度、速度数字），让评委看到物理模型落到了可执行的动作上。

## 来自精读

### 全文骨架

论文回答一个问题：**怎样击球（什么杆、什么角度、多大力量），球才能绕过树（圆柱）落在果岭圆内？**

```mermaid
flowchart LR
    A["§3 杆-球碰撞<br/>(1)-(6) 完全非弹性<br/>10 元线性方程组 → 初速+自旋"] --> B["§4 自由飞行<br/>(7)(8)(9) 阻力+Magnus<br/>三维 ODE 数值积分"]
    B --> C["§5 弹跳滚动<br/>(10)-(19) 恢复系数+Daish 反弹<br/>几何级数+滚动摩擦"]
    C --> D["§6 可行域+裕度<br/>(20) 扫 ψ-γ 平面 → M 最大化<br/>→ 教练式建议"]
    D --> E["§6.3 扩展<br/>侧风 5 m/s → 可行域变大"]
```

**为什么这个骨架好？** 题目说"describe the club/ball interaction"，作者就按**物理过程的时序**切三段（碰撞 0.5 ms → 飞行数秒 → 弹跳滚动），每段挑该段最合适的数学工具：碰撞=代数方程组、飞行=ODE、弹跳=级数。最后一段 §6 是点睛之笔：不满足于"存在可行解"，而是扫出**参数空间里的可行域**，再定义**裕度 M**（式 20）把"容不容许失误"变成可优化的标量——从解题升级为设计。

### 建模决策链

| 决策 | 作者的选择 | 被放弃的替代 | 为什么 |
|---|---|---|---|
| 过程切分 | 碰撞/飞行/弹跳三段 | 全程一体化 ODE | 各段物理与时间尺度截然不同（0.5 ms / 5 s / 数秒），一段一工具 |
| 碰撞模型 | 完全非弹性 + 矩阵 10 元 | 恢复系数式弹性碰撞 | 接触 <0.5 ms、力 >5 kN 的文献事实；矩阵可解可审 |
| 自由飞行 | 定自旋 + 阻力 + Magnus | 自旋衰减、风（后补） | 定自旋是主项；风作为扩展模型展示余量 |
| 弹跳模型 | Penner 拟合 e + Daish 公式 | 逐次弹跳数值仿真 | 经验公式有实验背书；首跳耗能 98.6% 使级数截断安全 |
| 结果呈现 | (ψ,γ) 可行域 + 裕度 M | 单条"成功轨迹" | 题目要"describe"，可行域才是完整描述；M 把容差变成优化目标 |
| 参数选择建议 | M 最大化 ⇒ V≈60、θ=π/8 | 试错挑选 | 优化目标显式、可复现 |
| 符号管理 | 两页符号表 + 矩阵逐行注释 | 行内随用随定义 | 30+ 符号的论文没有符号表等于埋雷 |

**总规律**：三段模型的"信任来源"各不相同——碰撞靠高速摄影、飞行靠空气动力学文献、弹跳靠 Penner 实验。**每一段都把信任外包给该领域最强的证据**，自己的贡献放在集成与优化层。
