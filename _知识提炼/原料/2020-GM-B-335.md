# 2020-GM-B-335（2020 题B · 队伍 335 · 19 页）

## 来自赏析

### 论文速览

题目要求确定 1.5 kg 四旋翼无人机（转子最大推力 7 N、臂长 0.5 m）能在目标点 20 cm 范围内悬停的最大风速，并强调真实风是脉动的。该队走"动力学建模 + 随机风场 + 闭环控制仿真"的完整工程路线：用 Newton-Euler 方程建立六自由度刚体动力学，用 Dryden 模型经成形滤波器生成湍流风，再用四路 PID（实际为 PD）控制器闭环仿真，逐步增大参考风速 $u_{20}$ 直至偏移超过 20 cm。最终结论：当湍流风 $u_{20}=23$ m/s 时偏移达 20 cm，对应合成风速 $\sqrt{7.51^2+6.24^2+4.20^2}=10.63$ m/s，与摘要完全一致。

### 获奖密码

1. **把"题眼"做成了控制问题。** 题目强调 real wind is not steady，该队没有用定常风做静态力平衡，而是 Dryden 随机风 + 闭环控制 + 蒙特卡洛式加大风速搜索临界值，正面回应了题目的动态本质。
2. **模型链条完整自洽。** 从气动诱导速度到 Newton-Euler 六自由度再到 $U/W$ 向量分解，每一层都有文献支撑，并用无风退化、垂直轴定理等快速自检，评委能顺着公式一路读通。
3. **答案精确且首尾呼应。** 摘要即给出 10.63 m/s，正文第 17 页用 $\sqrt{7.51^2+6.24^2+4.20^2}$ 复现同一数值，摘要—正文—结论三点一线。
4. **控制器整定有过程证据。** 不是直接"甩"出一组 PID 参数，而是 6 组扫描图对比收敛时间与振荡行为，体现工程判断（$K_p$ 过大电机会饱和、$K_d$ 过大高频振动）。
5. **诚实且具体的局限性讨论。** 列出 5 条局限并逐条给出改进方向（机身风阻、惯量精细计算、真实风数据、GA/Q-learning 整定、更精确湍流模型），展示元认知。

### 可借鉴清单

1. 遇到"环境随机扰动 + 保持精度"类题目，直接套用"Deterministic 动力学 + 成形滤波器造随机扰动 + 闭环控制 + 逐步加大扰动找临界值"的四段式框架。
2. Dryden 湍流模型的三方向功率谱、尺度与强度公式（含 $L_u = 2L_v = h/(0.177+0.000823h)^{1.2}$、$\sigma_w=0.1u_{20}$）可直接搬用，是给白噪声"染色"的最省力方案。
3. 让扰动只在有限时间窗内注入（如本文 $[4,10]$ s），便于分离"自由响应"与"受扰响应"，图面也更可读。
4. 参数整定务必给出扫描对比图（控制变量法、2×3 网格排版一页六图），一张图顶一页文字论证。
5. 把控制输入/扰动整理成 $U$、$W$ 向量的标准形式再设计控制器，能大幅简化推导书写并方便编程。
6. 结尾写"局限 + 改进"时给出具体可操作手段（如 GA、Q-learning、真实风数据），比空泛的"模型可进一步改进"更能赢得评委好感。

## 来自精读

### 全文骨架

论文回答：**1.5 kg 四旋翼（单桨 7 N、臂长 0.5 m）在湍流风里悬停，最大能扛多大风还能钉在目标点 20 cm 内？**

```mermaid
flowchart LR
    A["第1.1-1.2节<br/>坐标系 + Newton-Euler<br/>六自由度方程<br/>整理成 U/W 向量形式"] --> B["第1.3节<br/>Dryden 湍流模型<br/>白噪声→成形滤波器→三维湍流"]
    B --> C["第2.2节<br/>四路 PD 控制器<br/>Ki=0 + 参数扫描整定"]
    C --> D["闭环仿真<br/>逐步加大参考风速 u20"]
    D --> E["u20=23 m/s 时偏移=20 cm<br/>合成风速=10.63 m/s"]
```

**为什么这个骨架好？** 题目强调"真实风非定常"，多数队伍会用定常风做静态力平衡，该队正面迎接随机性：**Dryden 随机风 + 闭环控制 + 逐步加风找临界**。三块（对象、扰动、控制器）各自独立建模、在仿真环里闭合——这就是控制工程的"被控对象-扰动-反馈"标准三角。

### 建模决策链

| 决策 | 作者的选择 | 被放弃的替代 | 为什么 |
|---|---|---|---|
| 风模型 | Dryden 成形滤波湍流 | 定常风（静态力平衡）/ N-S 直接模拟 / Von Karman 谱 | 题目强调脉动；Dryden 有现成谱+滤波器二件套，成本最低 |
| 扰动注入方式 | 有限时间窗 [4,10] s | 全程湍流 | 分离自由/受扰响应，图面可读 |
| 机身风阻 | 忽略 | 计入机身气动力 | 迎风面积远小于桨盘[2]，量级论证 |
| 惯量 | 方板模型 + 垂直轴定理 | 精确 CAD/实验惯量 | 量级正确、解析可查；列为局限 |
| 控制器 | 四路 PD（Ki=0） | 全 PID / LQR / 反步法 | 零均值随机扰动下 I 项失效；PID 是"无精确模型也能用"的工程默认 |
| 参数整定 | 控制变量法 6 组扫描 | GA / Q-learning | 48 h 可完成；进化算法列为改进方向 |
| 临界值判据 | 偏移 20 cm（题面）+ 单调放大 u₂₀ | 二分搜索 | 同效，实现直白 |

**总规律**：每一层（气动、刚体、风、控制）都**先引一个成熟模型**（McCormick 气动、Newton-Euler、Dryden、PID），再做**一处关键简化并给出代价或理由**——工程论文的"站在巨人肩膀上再省一刀"。
