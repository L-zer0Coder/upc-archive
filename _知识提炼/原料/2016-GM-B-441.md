# 2016-GM-B-441（2016 题B · 队伍 441 · 16 页）

## 来自赏析

### 论文速览

论文采用 McNab (2009) 的"资源与能量决定体型上限"框架：物种日能耗服从异速标度律 $\mathrm{FEE}=aM^b$（式 1），环境给出每日最大可行能耗上限 $K$，联立即得最大体量 $M_{max}=(K/a)^{1/b}$——**指数 $b$ 各群相近（0.67-0.85），差异全部来自质量无关系数 $a$**：$a$ 越小，同等环境可养活的体重越大。团队用 Nagy 等 (1999) 的双标水法实测数据（79 种哺乳动物、55 种爬行动物）做对数线性回归验证模型（$r^2\approx0.95$），再以"最大哺乳动物 Paraceratherium（15 t）恰好触及 $K_m\approx8.94\times10^5$ kJ/d 且 $K_d\approx K_m$"为锚定假设，检验两种恐龙代谢假说：普通爬行动物参数只给出 $M_{max}\approx31.5$ t（比值 2.1，与 6.67 的实测比值矛盾），而巨蜥属（Varanus）参数给出 $M_{max}\approx158$ t、比值 10.54——成功解释一个数量级之差，并推论恐龙代谢介于外温与内温之间的中温型（mesothermy）。

### 获奖密码

1. **物理视角切入生物题**：把"为什么恐龙更大"转译为"能量可行性约束下的极值问题"，$M_{max}=(K/a)^{1/b}$ 一行公式给出全部解释力，模型简洁而参数可测。
2. **用真实数据自证模型**：亲自对 134 个物种的实测 FMR 重新回归（而非抄文献系数），报告 $r^2$ 与 p 值，并与两篇文献交叉核对——"evaluate the effectiveness using data"这一题目硬要求被超额完成。
3. **假设可否证、且真的去否证**：把"恐龙是爬行动物"变成可计算的预测（31.5 t），与 100 t 化石记录矛盾后明确否证，再引入 Varanus 假说得到 158 t/比值 10.54——完整的科学方法叙事，而非只讲支持性证据。
4. **参数 $a$ 的生物学含义被讲透**：$b\approx$ 常数、$a$ 承载群间差异的论证（§2.1.3），使"代谢效率差异是主因"的结论有清晰的机制落点。
5. **跨学科闭环**：§3.2.4 用传热学（Newton 冷却 + 球体标度）为古生物学争议（mesothermy，引 Grady 2014 Science）提供量级支持，物理竞赛味道十足。
6. **诚实的假设清单**：$K_d\approx K_m$ 的近似性质、6 样本的 Varanus 回归、未计太阳辐射，全部写明。

### 可借鉴清单

1. 生物/统计类题目先找"幂律 + 对数线性化"，回归时报告 n、$r^2$、p 值三件套。
2. 极值型问题找"自然实验"锚定环境上限参数（最重已知个体 ≈ 上限），把不可测的 $K$ 变可测。
3. 把对立假说都代入模型算出可否证的数值预测，用化石/观测数据裁决——展示科学方法而非单纯拟合。
4. 引入"生态等价种"配对比较（犀牛-三角龙），用区间重叠性做定性但有力的符合性判断。
5. 对模型隐含的物理合法性（如低代谢能否维持体温）做独立量级检查，防止结论被一票否决。
6. 质疑点写成 Further Investigations（改进 $K_d$、扩充数据），把弱点转化为研究路线图。

## 来自精读

### 全文骨架

题目问：为什么最大恐龙比最大陆地哺乳动物重一个数量级？论文的回答压缩成一行公式：**M_max=(K/a)^{1/b}**——环境给能耗封顶 K，物种内在代谢效率 a 决定同样的 K 能养活多大的身体。

```mermaid
flowchart LR
    A["§1 排除法立论<br/>环境因素会被演化绕过<br/>→ 主限制必是内在特性"] --> B["§2 模型<br/>FEE = aM^b + 上限 K<br/>大象-丛林思想实验给 K 物理图像"]
    B --> C["§3.1 数据验证<br/>134 物种 FMR 回归<br/>r²≈0.95, 与两文献交叉核对"]
    C --> D["§3.2 假设否证<br/>爬行类假说: 31.5 t ✗ (实测~100 t)<br/>Varanus 假说: 158 t ✓ 比值 10.54"]
    D --> E["§3.2.4 物理自洽检查<br/>Newton 冷却: 散热 3~116 kJ/s<br/>vs 代谢 7.5 kJ/s → 中温性可行"]
```

**为什么这个骨架好**：它是一堂浓缩的科学方法课——先排除竞争解释（§1）、再建可测模型（§2）、先用数据自证模型有效（§3.1）、再把对立假变成可否证的数值预测（§3.2）、最后检查结论的物理合法性（§3.2.4）。每个环节都在为"结论可信"加一层保险，而这五层保险的成本只是一条幂律和两次回归。

### 建模决策链

| 决策 | 作者的选择 | 被放弃的替代 | 为什么 |
|---|---|---|---|
| 解释变量 | 内在代谢效率 a | 环境因素（氧、温度） | 演化可绕过环境变化；两类动物共存过相似环境 |
| 模型形式 | 异速幂律 FEE=aM^b | 机理代谢模型（多参数） | 参数可实测（FMR 数据库），回归可检验 |
| b 的处理 | 引文献钉死在 0.67–0.85 | 各群自由拟合 b | 固定 b 才能把解释力集中到 a，避免过参数化 |
| K 的确定 | 最重化石个体锚定 | 从资源密度模型计算（式 2–5） | ε、α 无数据；锚定只需一个可靠化石质量 |
| 恐龙分类 | 假设-否证：爬行类 ✗ → Varanus ✓ | 直接假设恐龙=某类 | 可否证的预测（31.5 vs 100 t）让古生物争论变成计算题 |
| Varanus 样本 | 只取 >1.3 kg 的 6 种最重者 | 全部 Varanus 物种 | 恐龙质量段在外推方向上，回归应锚定在高质量端 |
| 预测对比 | 区间重叠性（Tables 3–4） | 点值误差百分比 | 化石质量估计本身是区间，语言要匹配不确定性 |
| 代谢率质疑 | 传热量级自查（式 12–16） | 回避/引用文献搪塞 | 结论的物理合法性必须自己验证；量级够用 |
| 数值方法 | 全解析+回归 | 数值模拟 | 数据只有 134 行，回归+幂律反解即完备；多余的机器是伪精度 |

**总规律**：**每个决策都在管理"自由度"**——固定 b、锚定 K、区间化比较，都是为了把唯一要回答的问题（a 谁小）放在证据最充分的位置。模型简单不是偷懒，是设计。
