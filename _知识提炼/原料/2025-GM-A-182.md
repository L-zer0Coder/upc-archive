# 2025-GM-A-182（2025 题A · 队伍 182 · 29 页）

## 来自赏析

### 论文速览

滑铁卢大学队把电沙桑托当作一个完整的"传感—滤波—放大—放声"系统工程来做：先从音色保真、噪声免疫与侵入性三个维度对比磁电/压电/光学三类拾音器并选定**光学拾音**（位移敏感、非接触）；再从一维波动方程出发证明拾音器应**紧贴琴码**放置（避免落在波节、保留高次谐波与动态余量）；滤波端用 RBJ biquad 带通滤波器复现叶共鸣器 98–1047 Hz 通带（$Q\approx0.34$，系数 $b=[0.059,0,-0.059]$、$a=[1.0,-1.9,0.88]$），并额外为 70 cm 闭管竹筒的四个谐振（245/490/735/980 Hz）各配一支 biquad，$Q=19\pm2$ 由竹材内摩擦 $\tan\delta=0.053\pm0.005$ 推出且做了误差传递；最后选 Class AB 功放与动圈扬声器，给出全信号链框图。

### 获奖密码

1. **传感物理讲透了**：以"位移敏感 vs 速度敏感"为主线，用对波函数求导导致 $1/n$ vs $1/n^2$ 谐波权重变化的数学论证解释磁拾音为何改变音色，选型有第一性原理支撑。
2. **每个设计决策都有推导出处**：拾音位置（波节分析）、滤波器中心频率与 $Q$（几何对称带通）、竹筒谐振（闭管驻波）、功放类型（效率对比），形成完整的工程决策链。
3. **误差传递到最终交付物**：从竹材内摩擦的 $\pm0.005$ 到滤波器系数的 $\pm10^{-4}$，把实验物理的误差分析纪律带入信号处理设计，评委极少见到。
4. **把题给的每个数字用足**：98/1047 Hz 决定通带，70 cm 决定驻波系列，8 cm 用于闭管判断，一个不落。
5. **完整系统观**：不满足于滤波器，而是给出拾音—前放—ADC—滤波—DAC—功放—扬声器全链路，并诚实讨论时延与多弦成本，工程可行性强。
6. **学术规范**：APA 引用与图片版权溯源一丝不苟，可信度高。

### 可借鉴清单

1. "传感器选型矩阵"写法：以保真度/灵敏度/抗扰/侵入性为维度逐一对比，并用物理推导（而非参数表）支撑结论。
2. 用 $A_n(P)=A_n\sin(n\pi P/L)$ 型"拾取位置×模态"分析回答"传感器放哪"，可推广到任何驻波系统（弦、管、梁）的测点布置。
3. 闭管/开管驻波公式 + 材料内摩擦 $Q=1/\tan\delta$，把"材料学数据 → 共振器 $Q$ 值 → 滤波器系数"串成一条可复用链条。
4. 对设计参数做全程不确定度传递，直到最终系数/结果，用 $\pm$ 区间呈现（本文 $\delta\alpha=\alpha\delta Q/Q$ 可直接套用）。
5. 用白噪声激励 + Welch PSD 实测滤波器响应，是验证数字滤波器最省事的黑箱方法（附录代码固定种子可复现）。
6. 全信号链框图 + 弱点自评（时延、成本、供电）收尾，让方案从"物理题答案"升级为"可实施设计"。

## 来自精读

### 全文骨架

论文回答一个问题：**用电拾音+扬声器替换叶共鸣器后，如何不丢掉传统沙桑托的音色？** 答案是一条完整的信号链设计：

```mermaid
flowchart LR
    A["§4 拾音器选型<br/>磁(速度敏感✗)/压电(侵入✗)<br/>→ 光学(位移敏感✓)"] --> B["§5 拾音位置<br/>波动方程分离变量<br/>→ 贴琴码(避波节)"]
    B --> C["§6 数字 biquad 带通<br/>叶共鸣器 98–1047 Hz Q=0.34<br/>+ 竹筒四谐振 Q=19±2"]
    C --> D["§7 Class AB 功放<br/>+ 动圈扬声器"]
    D --> E["§8-9 全链路框图<br/>+ 弱点自评(时延/成本)"]
```

**为什么这个骨架好**：四个决策不是并列的清单，而是**信号链的先后顺序**——传感器先定（决定音色保真的物理上限），位置再定（决定拾到的谐波结构），滤波器补共鸣（补上被替换掉的叶共振），功放收尾。每一步的输出是下一步的输入，评委顺着读就是一次信号流程图漫游。

### 建模决策链

| 决策 | 作者的选择 | 被放弃的替代 | 为什么 |
|---|---|---|---|
| 乐器形制 | gong 型、9–11 弦 | violin 型 32–36 弦 | 最简形制先把方法走通，弦数留在弱点自评 |
| 拾音器 | 光学（H21B1 光断续器） | 磁（改谐波权重+需铁弦）、压电（高阻+侵入琴码） | 位移敏感保音色、非接触、抗扰 |
| 拾音位置 | 紧贴琴码（P→0） | 管中部等"大信号"位置 | 避开一切波节、保谐波结构、headroom 大 |
| 共鸣复现 | 数字 biquad 并联组 | 模拟电路滤波器 | 参数可调、免元件容差、多共振零成本 |
| 叶通带 Q | 0.34（几何平均中心频率） | 高 Q 窄带 | 叶共鸣是宽带放大（98–1047 Hz），低 Q 物理自洽 |
| 竹筒 Q | 1/tanδ=19±2 | 拍脑袋常数 | 从材料 DMA 数据推出且带误差传递 |
| 采样率 | 48 kHz（AES 标准） | 44.1 kHz | 音频制作推荐值，防混叠、软件兼容 |
| 功放 | Class AB（η=50–70%） | A 类（效率低）、B 类（交越失真） | 效率与线性的折衷 |

**总规律**：每个决策都对应一条"物理机理或文献数据"，没有一条是"我们觉得"。加上把 tanδ 的 ±0.005 一路传到系数的 ±10⁻⁴，构成全文的可信度骨架。
