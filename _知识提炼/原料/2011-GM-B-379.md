# 2011-GM-B-379（2011 题B · 队伍 379 · 9 页）

## 来自赏析

### 论文速览

欧林工学院队（Schutzengel, Varin, Quinlivan）研究奥运规则下距篮筐 6.2 m、与场地主轴成 45° 处的三分球：哪些初速度 $(v_0,\varphi,\theta)$ 与后旋组合能命中。他们建立了"旋转篮球空气动力学 + 篮板/篮筐非弹性碰撞"两段式蒙特卡洛式扫描仿真：空中段用含 Magnus 力与阻力的运动方程（式 1）以 MATLAB ode45 积分，碰撞段用恢复系数冲量法 $\Delta\vec p=(1+\epsilon)\frac{\vec p\cdot\vec n}{\|\vec n\|^2}\vec n$ 反弹后续算，反复迭代直到球落入网中或出局。对 $(v_0,\varphi)$ 平面扫描绘出"命中区域图"：无旋时最佳约 9 m/s、仰角 0.85 rad；2 转/秒后旋使整个抛物线带向低速低角平移（Figure 4）；45° 方位角下打板球（θ≈0.825 rad 附近，Figure 5）的成功区域显著大于空心入筐区域，且没有擦筐蹦出的"混沌"边缘（Figure 6），故打板更稳妥。

### 获奖密码

1. **参数全面官方化**：球、筐、板的所有几何与恢复系数都取自 FIBA 官方规则文件并列表标注出处，把"假设清单"变成"数据清单"，评委无需质疑任何常数。
2. **物理要素齐全**：重力、阻力、Magnus 升力、非弹性碰撞、多次弹跳一应俱全，而大多数参赛队很可能只做了无旋抛体。
3. **降维有理有据**：6 维解空间通过"纯后旋"假设压到 2 维，既省算力又符合真实投篮姿态，并在 Discussion 中明说这是为可视化所做的取舍。
4. **结论具备"教练价值"**：后旋降低所需初速、高仰角容差更大、打板区更大且边缘不混沌——每条都是可执行的建议，回答了题目"什么样的速度与旋转会命中"的全部要点。
5. **独立文献交叉验证**：与 Silverberg 等人的已发表仿真对照，为自建模型提供外部效度。
6. **事件驱动多体碰撞框架**完整可复现（源码全文公开），碰撞-重置-续算的架构清晰。

### 可借鉴清单

1. **"空中 + 接触 + 空中"事件驱动仿真框架**：ode45/事件函数/恢复系数冲量三件套，可用于任何"飞行体碰壁/碰框"类题（网球、台球、冰壶），直接搬运。
2. **先列官方参数表再建模**：把能查到的所有尺寸、系数先做成 Table 并注来源，建模时"零自由参数"，大幅提升说服力。
3. **命中区域灰度图**是呈现"参数空间解集合"的最优方式：比单条轨迹曲线信息量大一个量级，评委一眼看出容差与最优工作点。
4. **把结论翻译成 practitioner 语言**（"高弧线容错更高""打板更稳"），呼应题目的现实语境，展示物理模型的实用价值。
5. **降维假设要服务可视化**：当解空间超维时，明确说明砍掉哪些维度、为什么合理（纯后旋 = 主流投篮方式）。
6. **教训**：正文多个拼写错误和 "Figure ??" 断链说明 48 小时内必须预留 1–2 小时纯校对时间——内容过硬也可能因细节失分。

## 来自精读

### 全文骨架

论文只回答一个问题：**站在三分线外 6.2 m、与场地主轴成 45° 的球员，用哪些初速度 (v₀, φ, θ) 与后旋组合能把球投进？**

```mermaid
flowchart LR
    A["§II 场景与几何<br/>FIBA 官方尺寸表<br/>坐标系 + 球坐标定义"] --> B["§III.A 空中段<br/>式(1)：重力+阻力+Magnus<br/>ode45 事件驱动积分"]
    B --> C["§III.B 碰撞段<br/>Δp=(1+ε)p·n/|n|²·n<br/>恢复系数取自 FIBA 规则"]
    C --> D["§IV 结果扫描<br/>Fig3/4: (v₀,φ) 命中区<br/>Fig5/6: 打板球区域"]
    D --> E["§V 讨论<br/>后旋省力；高弧容差大<br/>打板区域更大且边缘不混沌"]
```

**为什么这个骨架好？** 它是"**参数空间扫描**"型论文的标准件：模型只建一次（一段飞行 + 一族碰撞），然后把它当作黑箱函数，在 (v₀, φ) 或 (θ, φ) 平面上逐点调用，把"成功/失败"画成灰度图。问题问"哪些组合能进"，答案天然是一张**集合的地图**而不是一个数——图表即结论。另外全文参数策略非常极端：**没有一个自己拍脑袋的常数**——球、筐、板的几何与恢复系数全部来自 FIBA 官方规则文件，连"恢复系数 0.65–0.5"都是规则明文规定的区间。

### 建模决策链

| 决策 | 作者的选择 | 被放弃的替代 | 为什么 |
|---|---|---|---|
| 解空间 | 6 维 → 纯后旋假设 → 扫 2 维平面 | 全 6 维蒙特卡洛 | 可视化只能 2 维；纯后旋是主流投篮方式（行为依据） |
| 空气动力 | 重力+二次阻力+理想 Magnus | 加自旋衰减、侧旋、C_L(ω,r) 修正 | 主效应已覆盖；修正项小于恢复系数的不确定度 |
| 积分器 | ode45 + 事件函数（RelTol 1e-5） | 定步长 RK4 | 碰撞时刻需要事件定位精度；自适应步长处理速度突变 |
| 碰撞模型 | 无摩擦 + 恢复系数冲量 | 库仑摩擦+自旋耦合 | 摩擦系数无官方数据；代价（打板结果偏乐观）作者明说 |
| 碰撞对象几何 | 筐=圆环（点到环距离）、板=矩形（点到矩形距离） | 筐=圆柱面、板=有限厚 | 距离函数简单且有解析式；厚度效应 ≪ 球半径 |
| 参数来源 | FIBA 规则 + 文献（C_d=0.54） | 自测/估 | 零自由参数，评委无可质疑 |
| 结果呈现 | 命中区域灰度图 ×4 | 表格/单条最优轨迹 | 题目问"集合"，图的形状即论据（容差、碎斑、面积差） |
| 模型校验 | 与 Silverberg 等已发表罚球仿真对照 | 无校验 | 一句话获得外部效度 |

**总规律**：**"官方参数 + 事件驱动 + 集合扫描"三件套**——凡题目问"哪些条件能成功"（命中、入网、过关），直接套这套架构，替换其中的力学与碰撞几何即可。


**句式库（原文摘录，括号内为使用场景）**：
- "poses several interesting problems. Solving these problems requires ..."（开篇列全物理要素）
- "It was also assumed that ... this is the way most basketball players shoot."（降维假设配行为依据）
- "This simplifying assumption may have a measurable effect on the outcome"（主动指出假设影响了自己的核心结论）
- "These results are similar to those obtained by Silverberg, Tran and Adcock"（外部文献校验一句话）
- "It is worth noting that ..."（读图时把图形特征升级为论断）
