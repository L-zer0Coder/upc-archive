# UPC 新一届赛事入库 SOP

目标：把第 N 届的资料变成与 2010–2025 完全同构的档案（目录、命名、页面、索引），并重建网站。**全程对照既有年份的文件命名，不要发明新格式。**

## 阶段 0：抓取一手资料

1. 抓官网年份页：参照 `_工具脚本/_crawl.py` 的做法（requests + BeautifulSoup，输出 HTML 原件 + 提取文本 + PDF 链接清单到 `01_官网原始页面/`）。新增年份页命名：`<年>*/` 沿用现有模式。
2. 官方成绩单：下载 `<年>_UPC_Results.pdf` 到 `02_官方成绩单/<年>/`。
3. 金牌论文 PDF：下载到 `03_优秀论文PDF/<年>/Problem A|B/<原名>.pdf`。**保留官网原文件名**（`<年>-GM-<题>-<队伍号>.pdf` 模式）。注意去重：同文异版（如 2013 年 611/611a）只保留一个为正本，另建同名说明，赏析与精读挂在正本上，全库计数用独立论文数。

## 阶段 1：文本与元数据

4. 提取论文全文：`_工具脚本/_extract_text.py` → `04_论文文本/<年>/<base>.txt`；更新 `04_论文文本/_meta.json`（字段：year/problem/team/file/pages/first_lines，与现有条目完全同构）。
5. 页面渲染图：`_工具脚本/_render_pages.py` → `06_论文页面图/<年>/<base>_p1.png` 与 `_fig.png`。

## 阶段 2：内容层（用 Agent 批量生产，每批 4–6 篇，并发被拒就等待重试）

6. 题目汇总：`02_题目汇总/<年>_题目与官方信息.md`（英文原题全文 + 奖牌统计 + 金牌队伍名单 + 论文链接清单）——结构抄最近年份。
7. 题目深度解读：`07_题目解读/<年>_题<AB>_<中文短名>.md`（物理本质/建模路线图/常见陷阱/金牌思路对比/评分要点）——结构抄 `2010_题A_海王星气动制动.md`。
8. 每篇论文的赏析：`05_论文赏析/<年>/<base>.md`，固定六节：论文速览 / 建模体系逐层拆解 / 数学方法与算法 / 排版与图表赏析 / **获奖密码：为什么能拿金牌** / 可借鉴清单。
9. 每篇论文的精读：`10_论文精读/<年>/<base>_精读.md`，固定结构见 `_工具脚本/续作提示词.md`（一分钟骨架 mermaid / 逐节导读 / 图表深析含复现代码 / 公式逐条精讲 / 建模决策链 / 可复用模板）。

## 阶段 3：接线与重建

10. 更新 `_build_site.py` 顶部常量：`YEARS`、`CN`（年-题 → 中文名/英文名/物理域）、`INTERP`（年-题 → 解读文件名）、PHASES 不动。这四步漏一步该年就不出现在首页。
11. 提炼模式卡片：`python _工具脚本/_extract_knowledge.py && python _工具脚本/_aggregate_cards.py`（新论文的模式卡片逐篇补进 `_知识提炼/卡片/`，schema 见 `_知识提炼/卡片任务说明.md`）。
12. 全量重建：`python _工具脚本/_build_site.py` —— 构建期校验非零退出就按 `.agents/skills/upc-site-check` 修。
13. 更新 README（目录表、历年赛题表、年度注意事项如"官方未公开论文"）。
14. 提交推送：GitHub Pages 自动部署；提交信息按仓库惯例写清本次入库内容。

## 红线

- 不改历史年份的任何文件（除非修复错误，且单独提交说明）。
- `_meta.json` 改坏会炸全站索引——改前后各跑一次构建。
- 官网没公开的资料（如 2024 无论文）如实标注，不编造。
