# UPC 内容写作规范

本库 300+ 份内容文档有稳定的体例。新内容**必须与存量同构**：同样的章节骨架、同样的信息密度、同样的"每一条都落到论文证据"的纪律。

## 通用纪律

1. **全中文**正文，论文原句引用保留英文 + 中文解说。
2. 每个论断落到具体论文/公式/图（`2010-GM-A-160 式 (2.19)` 这种精度），不写"许多论文都…"。
3. 文件命名严格按目录惯例（`<base>.md`、`<base>_精读.md`、`<年>_题<AB>_<短名>.md`）；`<base>` 一律用官网 PDF 名去掉扩展名。
4. 标题一行含全量定位信息（见各体例首行）。
5. 数学用 `$...$`/`$$...$$`，构建期由 KaTeX 渲染；流程图用 mermaid 代码块。

## 各体例的结构基准（写之前先 Read 对应标杆）

| 内容类型 | 路径模式 | 标杆文件 |
|---|---|---|
| 论文赏析 | `05_论文赏析/<年>/<base>.md` | `05_论文赏析/2010/2010-GM-A-160.md`（六节：速览/建模拆解/数学算法/图表赏析/获奖密码/可借鉴清单） |
| 精读教程 | `10_论文精读/<年>/<base>_精读.md` | 标杆 `10_论文精读/2010/2010-GM-A-160_精读.md`；审计写法 `10_论文精读/2025/2025-GM-B-127_精读.md`；完整结构与逐节要求见 `_工具脚本/续作提示词.md` |
| 题目解读 | `07_题目解读/<年>_题<AB>_<短名>.md` | `07_题目解读/2010_题A_海王星气动制动.md` |
| 模型综述 | `08_物理模型综述/<NN>_<域名>.md` | `08_物理模型综述/01_航天与轨道动力学.md`（全景表 + 逐模型：适用场景/方程/建模要点/常见错误 + 套路总结 + 备赛建议） |
| 工具类 md | `11_论文模板与工具/` | 就地取材：同类现有文件的表格密度与"用法说明置顶"格式 |

## 篇幅与密度

- 赏析 3–6 KB；精读 15–25 KB（73 篇里最短的 17 KB、最长 111 KB，以讲透为准）；题目解读 8–15 KB。
- 表格优先于长段落：对比类信息（多篇论文/多个方案）一律表格化。
- 精读的复现代码必须可运行：常量注释对应论文式号、关键步骤有中文注释、结论写进图题。

## 构建联动

新 md 放进受索引目录后**必须重跑** `python _工具脚本/_build_site.py`——它自动渲染文档页、更新搜索索引并校验链接。新目录还要同步 `.gitignore` 白名单两处（见 upc-site-check 技能）。
