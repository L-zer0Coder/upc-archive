# UPC 档案库 · 网站蓝图与巡检标准

> 本文是全站的**唯一标尺**：先定义站点的完整逻辑与预期，之后所有巡检（内容盘点、点击走查）都对照本文执行。站点结构变更时先改本文再动代码。

## 一、使命与四类访客

一句话定位：**以 2010–2025 全档案为地基，服务"看懂金牌 → 练出能力 → 打完比赛"全周期的静态站点。**

| 访客 | 进入状态 | 期望旅程 | 首页落点 |
|---|---|---|---|
| A 新手 | 零经验，第一次接触 | 新手课堂三门课 → 零基础起步卡 → 数值实验台 → （循环） | hero「🎓 新手课堂」 |
| B 备赛者 | 有基础，练真题 | 年鉴/题目解读 → 赏析/精读 → 模型综述+闪卡 → 模板工坊+句库/润色库 | 「开始使用」指南 |
| C 赛时队伍 | 48h 高压 | 作战室（时间线/手册/终检/句库/中译英/导图/速查）+ 提示词工坊 + 规则合规卡 | 「⚡ 作战室」 |
| D 查阅者 | 找具体资料 | 全局搜索 / 论文库筛选 / 全库文件导航 / 规则与成绩单 | 搜索框 |

**判据**：四条旅程的每一跳都必须有可点击的入口，且 ≤2 跳可达目标页。

## 五、单一数据源规则（同一信息只允许一处定义）

1. 赛事时间与阶段表：`_build_site.py` 顶部（改完重建，全站同步）
2. 手册/终检/句库/润色库：`11_论文模板与工具/*.md` 是唯一源，工具页构建期解析注入
3. `.gitignore` 白名单：`.gitignore` 文件与 `_build_site_tail.py` 的 gi 模板**两处必须同步**
4. 起步卡模板：以 `2023_题A_太空跳伞_零基础起步卡.md` 为标杆；工具链接一律 `../12_赛时工具/`
5. 幻灯内链接：构建期断言（render_tutorial）
6. 计数：首页 NDOCS/闪卡/提示词自动；README 手动维护，巡检时对账

## 六、巡检流程（每次大改后执行）

1. `python _工具脚本/_build_site.py`（内含大小写+git 感知链接校验，非零即失败）
2. `python _工具脚本/_site_check.py`（独立体检）
3. 浏览器走查：本表「页面清单」逐页过一遍「必须能用」列
4. 内容抽审：每目录抽 1–2 份，查定位声明与质量
5. 移动端 390px 抽查首页 + 作战室 + 任一文档页
